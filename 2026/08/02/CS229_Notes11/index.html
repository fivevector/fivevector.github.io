CS229 Notes 11 : Unsupervised Learning (3) : Independent Components Analysis (ICA)

与 PCA 寻找“最大方差方向”不同，独立成分分析（ICA） 的目标是：从混合观测信号中恢复出相互独立的原始源信号。

一、鸡尾酒会问题

场景：ddd 个发言者同时说话，ddd 个麦克风放置在房间不同位置。每个麦克风记录的是所有发言者声音的线性混合，混合系数取决于麦克风与发言者的距离及房间声学特性。

数学形式：

  • 源信号：s∈Rds \in \mathbb{R}^ds∈Rd，各分量 sjs_jsj​ 表示第 jjj 位发言者在某一时刻的声音强度。各源信号统计独立。
  • 混合矩阵：A∈Rd×dA \in \mathbb{R}^{d \times d}A∈Rd×d，未知的方阵（通常假设满秩）。
  • 观测信号：x=Asx = A sx=As，即麦克风记录的混合信号。
  • 数据集：{x(i)}i=1n\{x^{(i)}\}_{i=1}^n{x(i)}i=1n​，nnn 次独立观测（不同时刻）。

目标：仅凭观测 x(i)x^{(i)}x(i)，估计解混矩阵 W=A−1W = A^{-1}W=A−1，使得恢复出的源信号为：

s(i)=Wx(i)s^{(i)} = W x^{(i)} s(i)=Wx(i)

记 WWW 的第 jjj 行为 wjTw_j^TwjT​，则第 jjj 个源信号可表示为：

sj(i)=wjTx(i)s_j^{(i)} = w_j^T x^{(i)} sj(i)​=wjT​x(i)

核心挑战：AAA 和 sss 均未知，仅知 xxx —— 这就是“盲”的含义。

二、ICA 的 Ambiguities

在不引入额外假设的情况下，仅凭 xxx 无法唯一确定 WWW：

2.1 Permutation Ambiguity

设 PPP 为任意 d×dd \times dd×d 排列矩阵。若用 APA PAP 代替 AAA，并用 P−1sP^{-1} sP−1s 代替 sss，则观测不变：

x=(AP)(P−1s)=A(PP−1)s=Asx = (A P)(P^{-1} s) = A (P P^{-1}) s = A s x=(AP)(P−1s)=A(PP−1)s=As

因此，我们无法区分 WWW 和 PWP WPW —— 即无法确定恢复出的源信号的顺序。这通常不影响应用（如语音分离只需提取各声音波形，不关心标签）。

2.2 Scaling Ambiguity

若将 AAA 的某一列乘以 α≠0\alpha \neq 0α=0，并将对应的 sjs_jsj​ 除以 α\alphaα，则观测不变：

x=(A⋅diag(αj))⋅(diag(αj−1)s)=Asx = (A \cdot \text{diag}(\alpha_j)) \cdot (\text{diag}(\alpha_j^{-1}) s) = A s x=(A⋅diag(αj​))⋅(diag(αj−1​)s)=As

因此，无法确定每个源信号的幅度（及符号）。对于语音等应用，幅度变化仅影响音量，无关紧要。

2.3 高斯源信号的性质

若源信号 s∼N(0,I)s \sim \mathcal{N}(0, I)s∼N(0,I)（标准高斯），则 x=Asx = A sx=As 的分布为 N(0,AAT)\mathcal{N}(0, A A^T)N(0,AAT)。对于任意正交矩阵 RRR（RRT=IR R^T = IRRT=I），定义 A′=ARA' = A RA′=AR，则 x′=A′sx' = A' sx′=A′s 的协方差为：

A′A′T=ARRTAT=AATA' A'^T = A R R^T A^T = A A^T A′A′T=ARRTAT=AAT

分布完全相同，无法区分 AAA 和 A′A'A′。这意味着存在任意旋转的模糊性，ICA 无法恢复源信号。

结论：ICA 可行的必要条件是：至多一个源信号服从高斯分布（若多个高斯源，则无法分离）。实践中，常假设源信号为非高斯（如超高斯或亚高斯分布）。

三、密度变换与似然函数

为了估计 WWW，我们需要建立观测数据 xxx 的概率模型。首先回顾线性变换的密度公式。

设随机向量 sss 具有密度 ps(s)p_s(s)ps​(s)。若 x=Asx = A sx=As，其中 AAA 是可逆方阵，令 W=A−1W = A^{-1}W=A−1，则 xxx 的密度为：

px(x)=ps(Wx)⋅∣det⁡(W)∣p_x(x) = p_s(W x) \cdot |\det(W)| px​(x)=ps​(Wx)⋅∣det(W)∣

标量示例：若 s∼Uniform[0,1]s \sim \text{Uniform}[0,1]s∼Uniform[0,1]，A=2A=2A=2，则 x=2sx=2sx=2s 均匀分布在 [0,2][0,2][0,2] 上，其密度为 1/21/21/2，而 ps(Wx)=ps(x/2)=1p_s(Wx) = p_s(x/2) = 1ps​(Wx)=ps​(x/2)=1，乘以 ∣W∣=1/2|W|=1/2∣W∣=1/2 得到正确结果。

由于源信号独立，其联合密度为各边缘密度的乘积：

ps(s)=∏j=1dps(sj)p_s(s) = \prod_{j=1}^d p_s(s_j) ps​(s)=j=1∏d​ps​(sj​)

我们需要选择 psp_sps​ 的具体形式。不能选择高斯分布（否则旋转模糊性导致不可辨识）。常用的选择是 sigmoid 函数的导数（即 logistic 分布的密度）：

ps(z)=g′(z),g(z)=11+e−z⇒ps(z)=e−z(1+e−z)2p_s(z) = g'(z), \quad g(z) = \frac{1}{1 + e^{-z}} \quad \Rightarrow \quad p_s(z) = \frac{e^{-z}}{(1+e^{-z})^2} ps​(z)=g′(z),g(z)=1+e−z1​⇒ps​(z)=(1+e−z)2e−z​

该密度是超高斯（尖峰重尾），适合许多自然信号（如语音）。

利用密度变换公式，观测数据 xxx 的密度为：

p(x;W)=(∏j=1dps(wjTx))⋅∣det⁡(W)∣p(x; W) = \left( \prod_{j=1}^d p_s(w_j^T x) \right) \cdot |\det(W)| p(x;W)=(j=1∏d​ps​(wjT​x))⋅∣det(W)∣

对于 nnn 个独立观测（假设各时刻独立，实际语音相关但通常近似处理），对数似然为：

四、ICA 的优化算法：随机梯度上升

我们通过最大化对数似然来估计 WWW。采用随机梯度上升（逐样本更新）。

对于单个样本 xxx，对数似然贡献为：

ℓ(W)=∑j=1dlog⁡ps(wjTx)+log⁡∣det⁡(W)∣\ell(W) = \sum_{j=1}^d \log p_s(w_j^T x) + \log |\det(W)| ℓ(W)=j=1∑d​logps​(wjT​x)+log∣det(W)∣

对 WWW 求梯度，利用矩阵微分：

  • ∇Wlog⁡∣det⁡(W)∣=(W−1)T\nabla_W \log |\det(W)| = (W^{-1})^T∇W​log∣det(W)∣=(W−1)T（因为 ∇Wdet⁡(W)=det⁡(W)(W−1)T\nabla_W \det(W) = \det(W) (W^{-1})^T∇W​det(W)=det(W)(W−1)T）。
  • 对于每个 jjj，∇wjlog⁡ps(wjTx)=ps′(wjTx)ps(wjTx)⋅x\nabla_{w_j} \log p_s(w_j^T x) = \frac{p_s'(w_j^T x)}{p_s(w_j^T x)} \cdot x∇wj​​logps​(wjT​x)=ps​(wjT​x)ps′​(wjT​x)​⋅x。

若 ps=g′p_s = g'ps​=g′，则 g′′(z)g′(z)=1−2g(z)\frac{g''(z)}{g'(z)} = 1 - 2g(z)g′(z)g′′(z)​=1−2g(z)（可通过求导验证）。
