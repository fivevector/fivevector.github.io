Minimum Spanning Tree

This article is based on the lecture notes of CS2501H(SJTU).

Definition:
A minimum spanning tree(MST) in a connected weighted graph is a spanning tree that has the
smallest possible sum of weights of its edges.

Prim’s Algorithm

Prim’s idea is to start with an arbitrary vertex and grow the tree by adding the smallest edge that connects a vertex in the tree to a vertex outside the tree, until all vertices are included.

Construct a minimum spanning tree of G=(V,E)G=(V,E)G=(V,E) according to the following steps:

  • Choose the initial tree T0=(V0,E0)T_{0}=(V_{0},E_{0})T0​=(V0​,E0​) as an arbitrary singleton vertex with no edges.

  • Construct Tn+1T_{n+1}Tn+1​ from TnT_{n}Tn​ by adding an edge en+1e_{n+1}en+1​ with minimum weight among all remaining edges e′e'e′ satisfying that the graph TnT_{n}Tn​ added with e′e^{\prime}e′ is a tree.

  • Finally T∣V∣−1T_{|V|-1}T∣V∣−1​ is a minimum spanning tree.

Key Step:

Find en+1e_{n+1}en+1​ such that:

  • en+1e_{n+1}en+1​ connects two vertices un+1u_{n+1}un+1​ and vn+1v_{n+1}vn+1​, one of which (suppose it is un+1u_{n+1}un+1​) is in VnV_{n}Vn​ and the other (vn+1)(v_{n+1})(vn+1​) is in V\VnV\backslash V_{n}V\Vn​.

  • If there are more than one minimum weighted edges, choose arbitrary one.

  • Tn+1=(Vn+1,En+1)T_{n+1}=(V_{n+1},E_{n+1})Tn+1​=(Vn+1​,En+1​) where Vn+1=Vn∪{vn+1}V_{n+1}=V_{n}\cup\{v_{n+1}\}Vn+1​=Vn​∪{vn+1​} and En+1=En∪{en+1}E_{n+1}=E_{n}\cup\{e_{n+1}\}En+1​=En​∪{en+1​}.

The result of Prim’s algorithm is a minimum spanning tree.

Proof.

By induction on nnn that there exists a minimum spanning tree T∗T^{*}T∗ such that TnT_{n}Tn​ is a subgraph of T∗T^{*}T∗.

  • When n=0n=0n=0, we can choose an arbitrary minimum spanning tree as T∗T^{*}T∗.

  • When n=∣V∣−1n=|V|-1n=∣V∣−1, if we already know there exists a minimum spanning tree T∗T^{*}T∗ such that T∣V∣−1T_{|V|-1}T∣V∣−1​ is a subgraph of T∗T^{*}T∗, then T∗T^{*}T∗ must be T∣V∣−1T_{|V|-1}T∣V∣−1​ itself. We are done.

The only thing left is the induction step: assuming there exists a minimum spanning tree T∗T^{*}T∗ such that TnT_{n}Tn​ is a subgraph of T∗T^{*}T∗, we need to show that there also exists a minimum spanning tree (maybe different from T∗T^{*}T∗) such that Tn+1T_{n+1}Tn+1​ is a subgraph of it.

  • Choose an arbitrary minimum spanning tree T∗T^{*}T∗ such that TnT_{n}Tn​ is a subgraph of T∗T^{*}T∗.

  • If Tn+1T_{n+1}Tn+1​ is a subgraph of T∗T^{*}T∗, then we are done. Otherwise, we can always change an edge in T∗T^{*}T∗ so that Tn+1T_{n+1}Tn+1​ is a subgraph of T∗T^{*}T∗.

Here is how to change the edge. Since Tn+1T_{n+1}Tn+1​ is not a subgraph of T∗T^{*}T∗, en+1e_{n+1}en+1​ is not an edge in T∗T^{*}T∗. Because T∗T^{*}T∗ is a spanning tree, there is a path in T∗T^{*}T∗ between un+1u_{n+1}un+1​ and vn+1v_{n+1}vn+1​. On this path, there must be an edge e∗e^{*}e∗ leaving VnV_{n}Vn​ (e∗e^{*}e∗ connects a vertex in VnV_{n}Vn​ and a vertex in V\VnV\backslash V_{n}V\Vn​). Otherwise, there will be a path in TnT_{n}Tn​ between un+1u_{n+1}un+1​ and vn+1v_{n+1}vn+1​, which contradicts the fact that TTT is a tree.

Because of the choice of en+1e_{n+1}en+1​, w(e∗)≥w(en+1)w(e^{*})\ge w(e_{n+1})w(e∗)≥w(en+1​). On the other hand, because T∗T^{*}T∗ is a minimum spanning tree, w(e∗)≤w(en+1)w(e^{*})\le w(e_{n+1})w(e∗)≤w(en+1​). T∗\{e∗}∪{en+1}T^{*}\backslash\{e^{*}\}\cup\{e_{n+1}\}T∗\{e∗}∪{en+1​} is a tree. Thus, if we change e∗e^{*}e∗ to en+1e_{n+1}en+1​ in T∗T^{*}T∗, we will get another minimum spanning tree containing Tn+1T_{n+1}Tn+1​ as a subgraph.

Qed.

The time complexity of Prim’s algorithm is O(∣E∣log⁡∣V∣)O(|E|\log|V|)O(∣E∣log∣V∣) if we use a binary heap to implement the priority queue.(Every edge is visited at most twice, and each visit takes O(log⁡∣V∣)O(\log|V|)O(log∣V∣) time to decrease the key of a vertex in the priority queue in the worst case.)

Kruskal’s Algorithm

Construct a minimum spanning tree of G=(V,E)G=(V,E)G=(V,E) according to the following steps:

  • Choose the initial graph G0=(V,E0)G_{0}=(V,E_{0})G0​=(V,E0​) where E0=∅E_{0}=\varnothingE0​=∅.

  • Construct Gn+1G_{n+1}Gn+1​ from GnG_{n}Gn​ by adding an edge en+1e_{n+1}en+1​ with minimum weight among all remaining edges e′e^{\prime}e′ satisfying that the graph GnG_{n}Gn​ added with e′e^{\prime}e′ has no simple circuit. (If more than one edge e′e^{\prime}e′ has minimum weight, pick arbitrary one.)

  • Finally, G∣V∣−1G_{|V|-1}G∣V∣−1​ is a minimum spanning tree.

Here Gn+1=(V,En+1)G_{n+1}=(V,E_{n+1})Gn+1​=(V,En+1​) where En+1=En∪{en+1}E_{n+1}=E_{n}\cup\{e_{n+1}\}En+1​=En​∪{en+1​}.

The result of Kruskal’s algorithm is a minimum spanning tree.

Proof.

By induction on nnn that there exists a minimum spanning tree T∗T^{*}T∗ such that GnG_{n}Gn​ is a subgraph of T∗T^{*}T∗.

  • When n=0n=0n=0, we can choose an arbitrary minimum spanning tree as T∗T^{*}T∗.

  • When n=∣V∣−1n=|V|-1n=∣V∣−1, if we already know there exists a minimum spanning tree T∗T^{*}T∗ such that G∣V∣−1G_{|V|-1}G∣V∣−1​ is a subgraph of T∗T^{*}T∗, then T∗T^{*}T∗ must be G∣V∣−1G_{|V|-1}G∣V∣−1​ itself. We are done.

The only thing left is the induction step: assuming there exists a minimum spanning tree T∗T^{*}T∗ such that GnG_{n}Gn​ is a subgraph of T∗T^{*}T∗, we need to show that there also exists a minimum spanning tree (maybe different from T∗T^{*}T∗) such that Gn+1G_{n+1}Gn+1​ is a subgraph of it.

  • Choose an arbitrary minimum spanning tree T∗T^{*}T∗ such that GnG_{n}Gn​ is a subgraph of T∗T^{*}T∗.

  • If Gn+1G_{n+1}Gn+1​ is a subgraph of T∗T^{*}T∗, then we are done. Otherwise, we can always change an edge in T∗T^{*}T∗ so that Gn+1G_{n+1}Gn+1​ is a subgraph of T∗T^{*}T∗.

Here is how to change the edge. Since Gn+1G_{n+1}Gn+1​ is not a subgraph of T∗T^{*}T∗, en+1e_{n+1}en+1​ is not an edge in T∗T^{*}T∗. Because T∗T^{*}T∗ is a spanning tree, there is a path in T∗T^{*}T∗ between the endpoints of en+1e_{n+1}en+1​. On this path, there must be an edge e∗e^{*}e∗ crossing the cut defined by the endpoints of en+1e_{n+1}en+1​. Otherwise, there will be a path in GnG_{n}Gn​ between the endpoints of en+1e_{n+1}en+1​, which contradicts the fact that GnG_{n}Gn​ is a forest.

Because of the choice of en+1e_{n+1}en+1​, w(e∗)≥w(en+1)w(e^{*})\ge w(e_{n+1})w(e∗)≥w(en+1​). On the other hand, because T∗T^{*}T∗ is a minimum spanning tree, w(e∗)≤w(en+1)w(e^{*})\le w(e_{n+1})w(e∗)≤w(en+1​). T∗\{e∗}∪{en+1}T^{*}\backslash\{e^{*}\}\cup\{e_{n+1}\}T∗\{e∗}∪{en+1​} is a tree. Thus, if we change e∗e^{*}e∗ to en+1e_{n+1}en+1​ in T∗T^{*}T∗, we will get another minimum spanning tree containing Gn+1G_{n+1}Gn+1​ as a subgraph.

Qed.

The time complexity of Kruskal’s algorithm is O(∣E∣log⁡∣E∣)O(|E|\log|E|)O(∣E∣log∣E∣), which is equivalent to O(∣E∣log⁡∣V∣)O(|E|\log|V|)O(∣E∣log∣V∣) in a connected graph. (Sorting the edges takes O(∣E∣log⁡∣E∣)O(|E|\log|E|)O(∣E∣log∣E∣) time, and the union-find operations take O(∣E∣α(∣V∣))O(|E|\alpha(|V|))O(∣E∣α(∣V∣)) time, where α\alphaα is the inverse Ackermann function, which is very slow-growing and can be considered almost constant for all practical purposes.)
