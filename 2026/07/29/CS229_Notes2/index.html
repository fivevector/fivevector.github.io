CS229 Notes 2 : Generative Learning Algorithms

这个系列是本人学习 CS229 的学习笔记。本文对应 Lecture Notes：Generative Learning Algorithms。

一、生成学习算法引论

在之前的监督学习讨论中，我们主要关注判别学习算法（Discriminative Learning Algorithms）。这类算法试图直接学习决策边界，即直接建模条件概率 p(y∣x)p(y|x)p(y∣x)（如逻辑回归）或找到一个直接从输入空间 X\mathcal{X}X 映射到标签 {0,1}\{0,1\}{0,1} 的函数（如感知机算法）。

然而，我们可以换一种完全不同的思路来解决分类问题。以区分“大象（y=1y=1y=1）”和“狗（y=0y=0y=0）”为例：

  1. 判别式思路：在特征空间中找一条直线（决策边界），将大象和狗的样本分开。新样本落在哪一侧，就归为哪一类。
  2. 生成式思路：首先，仔细研究大象的特征分布，建立一个“大象模型” p(x∣y=1)p(x|y=1)p(x∣y=1)；然后，仔细研究狗的特征分布，建立一个“狗模型” p(x∣y=0)p(x|y=0)p(x∣y=0)。当新样本到来时，我们将它与两个模型分别比对，看它更像大象还是更像狗。

定义 1（生成学习算法，Generative Learning Algorithm）
生成学习算法并不直接对 p(y∣x)p(y|x)p(y∣x) 建模，而是对联合概率分布 p(x,y)p(x, y)p(x,y) 建模。具体来说，它会学习：

  1. 类先验（Class Prior）：p(y)p(y)p(y)。
  2. 类条件密度（Class-Conditional Density）：p(x∣y)p(x|y)p(x∣y)。

利用贝叶斯规则（Bayes Rule），我们可以推导出后验分布：

p(y∣x)=p(x∣y)p(y)p(x)p(y|x) = \frac{p(x|y)p(y)}{p(x)} p(y∣x)=p(x)p(x∣y)p(y)​

其中，证据（Evidence） p(x)=∑yp(x∣y)p(y)p(x) = \sum_y p(x|y)p(y)p(x)=∑y​p(x∣y)p(y) 与 yyy 无关。因此，在预测时，我们只需计算：

arg⁡max⁡yp(y∣x)=arg⁡max⁡yp(x∣y)p(y)\arg\max_y p(y|x) = \arg\max_y p(x|y)p(y) argymax​p(y∣x)=argymax​p(x∣y)p(y)

二、高斯判别分析（Gaussian Discriminant Analysis, GDA）

GDA 适用于输入特征 xxx 为连续值向量的场景，核心假设是 p(x∣y)p(x|y)p(x∣y) 服从多元正态分布。

2.1 多元正态分布（Multivariate Normal Distribution）

先回顾一下多元正态分布的性质。一个 nnn 维的多元正态分布由均值向量 μ∈Rn\mu \in \mathbb{R}^nμ∈Rn 和协方差矩阵 Σ∈Rn×n\Sigma \in \mathbb{R}^{n \times n}Σ∈Rn×n（对称且半正定）参数化，记为 N(μ,Σ)\mathcal{N}(\mu, \Sigma)N(μ,Σ)。其概率密度函数为：

p(x;μ,Σ)=1(2π)n/2∣Σ∣1/2exp⁡(−12(x−μ)TΣ−1(x−μ))p(x;\mu,\Sigma) = \frac{1}{(2\pi)^{n/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x-\mu)^T \Sigma^{-1}(x-\mu)\right) p(x;μ,Σ)=(2π)n/2∣Σ∣1/21​exp(−21​(x−μ)TΣ−1(x−μ))

其中 ∣Σ∣|\Sigma|∣Σ∣ 表示矩阵 Σ\SigmaΣ 的行列式。

性质 1（期望与协方差）
若 X∼N(μ,Σ)X \sim \mathcal{N}(\mu, \Sigma)X∼N(μ,Σ)，则其期望 E[X]=μ\mathbb{E}[X] = \muE[X]=μ，协方差矩阵 Cov(X)=Σ\mathrm{Cov}(X) = \SigmaCov(X)=Σ。

Cov(Z)=E[(Z−E[Z])(Z−E[Z])T]=E[ZZT]−(E[Z])(E[Z])T\mathrm{Cov}(Z) = \mathbb{E}[(Z - \mathbb{E}[Z])(Z - \mathbb{E}[Z])^T] = \mathbb{E}[ZZ^T] - (\mathbb{E}[Z])(\mathbb{E}[Z])^T Cov(Z)=E[(Z−E[Z])(Z−E[Z])T]=E[ZZT]−(E[Z])(E[Z])T

直观理解协方差矩阵 Σ\SigmaΣ 的作用：

  • 对角元素 (Σii\Sigma_{ii}Σii​)：控制第 iii 个维度的方差。值越大，分布在该维度上越“扁平”或“分散”。
  • 非对角元素 (Σij\Sigma_{ij}Σij​)：控制第 iii 维与第 jjj 维之间的相关性。
    • 当 Σ=I\Sigma = IΣ=I（标准正态）时，密度图像呈圆形。
    • 当 Σ\SigmaΣ 的对角元素增大时，分布会在对应坐标轴方向拉长。
    • 当非对角元素增大时，椭圆（等高线）会发生旋转。例如，若 Σ12>0\Sigma_{12} > 0Σ12​>0，则 x1x_1x1​ 与 x2x_2x2​ 正相关，密度等高线会沿 45∘45^\circ45∘ 方向（即 x1=x2x_1 = x_2x1​=x2​ 方向）压缩。
    • 更一般地，通过特征分解 Σ=UΛUT\Sigma = U\Lambda U^TΣ=UΛUT，我们可以看出，高斯分布的等高线是椭圆（或椭球），其主轴方向由特征向量 UUU 决定，轴长由特征值 Λ\LambdaΛ 决定。

  • μ0\mu_0μ0​ 和 μ1\mu_1μ1​ 纯粹是各类别样本的均值中心。
  • Σ\SigmaΣ 的计算非常巧妙：它分别计算每个样本相对于其所在类别中心的散度矩阵（外积），然后对所有样本取平均。由于共享协方差假设，我们相当于用所有样本的信息来估计一个“平均”的协方差结构，这使得决策边界变为线性（如果每个类别有自己的 Σ\SigmaΣ，则决策边界是二次的，即 QDA）。

2.4 决策边界与可视化

当我们将两个高斯分布以及先验概率代入贝叶斯公式后，计算 p(y=1∣x)=0.5p(y=1|x) = 0.5p(y=1∣x)=0.5 的等高线，我们会发现这是一条直线。

为什么是直线？我们可以对贝叶斯公式取对数，得到判别函数 δ(x)=log⁡p(y=1∣x)p(y=0∣x)\delta(x) = \log\frac{p(y=1|x)}{p(y=0|x)}δ(x)=logp(y=0∣x)p(y=1∣x)​。代入高斯密度表达式，δ(x)\delta(x)δ(x) 中的二次项 (xTΣ−1x)(x^T\Sigma^{-1}x)(xTΣ−1x) 会相互抵消，只剩下一项关于 xxx 的线性函数 θTx\theta^T xθTx。因此，决策边界是线性的。

2.5 深入讨论：GDA 与逻辑回归

这是一个极其重要的理论联系。我们可以证明，如果 p(x∣y)p(x|y)p(x∣y) 是共享 Σ\SigmaΣ 的高斯分布，那么后验 p(y=1∣x)p(y=1|x)p(y=1∣x) 恰好是逻辑回归的形式：

p(y=1∣x;ϕ,Σ,μ0,μ1)=11+exp⁡(−θTx)p(y=1|x;\phi, \Sigma, \mu_0, \mu_1) = \frac{1}{1 + \exp(-\theta^T x)} p(y=1∣x;ϕ,Σ,μ0​,μ1​)=1+exp(−θTx)1​

其中 θ\thetaθ 是 ϕ,Σ,μ0,μ1\phi, \Sigma, \mu_0, \mu_1ϕ,Σ,μ0​,μ1​ 的某个函数。

然而，这个关系的逆命题不成立。也就是说，p(y∣x)p(y|x)p(y∣x) 符合逻辑函数，并不意味着 p(x∣y)p(x|y)p(x∣y) 一定是高斯分布。例如，如果 x∣y=0∼Poisson(λ0)x|y=0 \sim \mathrm{Poisson}(\lambda_0)x∣y=0∼Poisson(λ0​) 且 x∣y=1∼Poisson(λ1)x|y=1 \sim \mathrm{Poisson}(\lambda_1)x∣y=1∼Poisson(λ1​)，其后验 p(y∣x)p(y|x)p(y∣x) 同样具有逻辑函数形式。

  • GDA（强假设）：做出了更强的建模假设（数据必须是高斯分布）。如果这个假设是正确的，GDA 是渐近有效的（Asymptotically Efficient）。这意味着在数据量极大时，没有别的算法（包括逻辑回归）能比 GDA 更好（方差更小）。在小样本下，GDA 通常也表现更好。
  • 逻辑回归（弱假设）：做出了更弱的假设。它对于数据分布（无论是高斯、泊松还是其他指数族分布）都具有很好的鲁棒性（Robust）。如果数据确实是非高斯的（例如离散计数数据），那么在大量数据下，逻辑回归的泛化性能几乎总是优于 GDA。

三、朴素贝叶斯（Naive Bayes）

GDA 处理的是连续特征。现在我们来处理离散特征的分类问题，最经典的应用场景是文本分类（如垃圾邮件过滤）。

3.1 问题设定与特征表示

四、拉普拉斯平滑（Laplace Smoothing）

尽管朴素贝叶斯已经很强大，但它有一个致命的缺陷：零概率问题（Zero Probability Problem）。

4.1 问题阐述：零概率导致 NaN

假设在训练集中，某个单词（比如“NIPS”）从未出现过。那么根据上述 MLE，ϕ35000∣y=1=0\phi_{35000|y=1} = 0ϕ35000∣y=1​=0 且 ϕ35000∣y=0=0\phi_{35000|y=0} = 0ϕ35000∣y=0​=0。当一封新邮件包含“NIPS”时，预测公式中的连乘项 ∏j=1np(xj∣y)\prod_{j=1}^n p(x_j|y)∏j=1n​p(xj​∣y) 会因为乘以 0 而变成 0。最终分子分母均为 0，即 0/00/00/0，算法彻底失效。

从统计学角度来看，用有限训练集中事件的频率来估计概率，将未出现事件的概率估计为 0 是一个糟糕的偏差。

4.2 解决方案：拉普拉斯平滑

假设我们有一个取值为 {1,…,k}\{1, \dots, k\}{1,…,k} 的多项式随机变量 zzz，极大似然估计为 ϕj=∑i=1m1{z(i)=j}m\phi_j = \frac{\sum_{i=1}^m \mathbf{1}\{z^{(i)}=j\}}{m}ϕj​=m∑i=1m​1{z(i)=j}​。

定义 3（拉普拉斯平滑）
拉普拉斯平滑将上述估计修正为：

ϕj=∑i=1m1{z(i)=j}+1m+k\phi_j = \frac{\sum_{i=1}^m \mathbf{1}\{z^{(i)}=j\} + 1}{m + k} ϕj​=m+k∑i=1m​1{z(i)=j}+1​

这种修正保证了：

  1. 所有的 ϕj>0\phi_j > 0ϕj​>0，不再有零概率。
  2. ∑j=1kϕj=1\sum_{j=1}^k \phi_j = 1∑j=1k​ϕj​=1，仍然满足概率公理。
  3. 在贝叶斯推断中，这等价于给参数 ϕ\phiϕ 施加了一个均匀先验分布（Dirichlet(1)）。

应用到朴素贝叶斯：
对于二元特征（取值为 0 或 1，即 k=2k=2k=2），我们得到：

ϕj∣y=1=∑i=1m1{xj(i)=1∧y(i)=1}+1∑i=1m1{y(i)=1}+2ϕj∣y=0=∑i=1m1{xj(i)=1∧y(i)=0}+1∑i=1m1{y(i)=0}+2\begin{aligned} \phi_{j|y=1} &= \frac{\sum_{i=1}^m \mathbf{1}\{x_j^{(i)}=1 \land y^{(i)}=1\} + 1}{\sum_{i=1}^m \mathbf{1}\{y^{(i)}=1\} + 2} \\ \phi_{j|y=0} &= \frac{\sum_{i=1}^m \mathbf{1}\{x_j^{(i)}=1 \land y^{(i)}=0\} + 1}{\sum_{i=1}^m \mathbf{1}\{y^{(i)}=0\} + 2} \end{aligned} ϕj∣y=1​ϕj∣y=0​​=∑i=1m​1{y(i)=1}+2∑i=1m​1{xj(i)​=1∧y(i)=1}+1​=∑i=1m​1{y(i)=0}+2∑i=1m​1{xj(i)​=1∧y(i)=0}+1​​

（在实践中，我们通常不对 ϕy\phi_yϕy​ 做平滑，因为如果训练集足够大，ϕy\phi_yϕy​ 为 0 的概率极低。）

五、文本分类的多项式事件模型（Multinomial Event Model）

前文介绍的多元伯努利模型虽然简单，但它丢失了词频信息。它只关心“单词是否出现”，而不关心“单词出现了几次”。多项式事件模型是文本分类中另一种更常用、通常效果更好的变体。

5.1 建模过程与符号定义

在多项式事件模型中，我们改变符号定义：

  • 训练集为 {(x(i),y(i))}i=1m\{(x^{(i)}, y^{(i)})\}_{i=1}^m{(x(i),y(i))}i=1m​，其中 x(i)x^{(i)}x(i) 是第 iii 封邮件的单词序列。
  • 设 nin_ini​ 为第 iii 封邮件的总词数。
  • 特征 xj(i)x_j^{(i)}xj(i)​ 表示第 iii 封邮件中第 jjj 个位置的单词在词汇表中的索引（取值范围为 {1,…,∣V∣}\{1, \dots, |V|\}{1,…,∣V∣}）。

生成过程（Generative Process）：

  1. 根据先验 p(y)p(y)p(y) 确定这是垃圾邮件还是正常邮件。
  2. 发送者从词汇表的多项式分布 p(xj∣y)p(x_j|y)p(xj​∣y) 中独立地抽取每个位置的单词，直到生成整封邮件。

因此，邮件的概率为：p(y)∏j=1nip(xj∣y)p(y) \prod_{j=1}^{n_i} p(x_j|y)p(y)∏j=1ni​​p(xj​∣y)。

5.2 参数估计与平滑

模型的参数为：

  • ϕy=p(y)\phi_y = p(y)ϕy​=p(y)
  • ϕk∣y=1=p(xj=k∣y=1)\phi_{k|y=1} = p(x_j = k|y=1)ϕk∣y=1​=p(xj​=k∣y=1)（任一位置的单词为词汇表中第 kkk 个词的概率，且该概率与位置 jjj 无关）
  • ϕk∣y=0=p(xj=k∣y=0)\phi_{k|y=0} = p(x_j = k|y=0)ϕk∣y=0​=p(xj​=k∣y=0)

定理 3（多项式事件模型的 MLE 与平滑）
该模型的极大似然估计（带拉普拉斯平滑）为：

ϕk∣y=1=∑i=1m∑j=1ni1{xj(i)=k∧y(i)=1}+1∑i=1m1{y(i)=1}ni+∣V∣ϕk∣y=0=∑i=1m∑j=1ni1{xj(i)=k∧y(i)=0}+1∑i=1m1{y(i)=0}ni+∣V∣\begin{aligned} \phi_{k|y=1} &= \frac{\sum_{i=1}^m \sum_{j=1}^{n_i} \mathbf{1}\{x_j^{(i)}=k \land y^{(i)}=1\} + 1}{\sum_{i=1}^m \mathbf{1}\{y^{(i)}=1\} n_i + |V|} \\ \phi_{k|y=0} &= \frac{\sum_{i=1}^m \sum_{j=1}^{n_i} \mathbf{1}\{x_j^{(i)}=k \land y^{(i)}=0\} + 1}{\sum_{i=1}^m \mathbf{1}\{y^{(i)}=0\} n_i + |V|} \end{aligned} ϕk∣y=1​ϕk∣y=0​​=∑i=1m​1{y(i)=1}ni​+∣V∣∑i=1m​∑j=1ni​​1{xj(i)​=k∧y(i)=1}+1​=∑i=1m​1{y(i)=0}ni​+∣V∣∑i=1m​∑j=1ni​​1{xj(i)​=k∧y(i)=0}+1​​

对比多元伯努利模型，这里的分子统计的是单词出现的总次数（而不是文档数），分母是该类别下所有邮件的总词数加上词汇表大小 ∣V∣|V|∣V∣（因为每个位置有 ∣V∣|V|∣V∣ 种可能取值）。
