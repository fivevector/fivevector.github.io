CS229 Notes 10 : Unsupervised Learning (2) : PCA

CS229 Notes 10 : Unsupervised Learning (2) : PCA

在机器学习中，数据往往存在冗余。例如，一个汽车数据集包含两个特征：xix_ixi​（英里/小时）和 xjx_jxj​（公里/小时）。两者几乎线性相关（xj≈1.609⋅xix_j \approx 1.609 \cdot x_ixj​≈1.609⋅xi​），仅由四舍五入引入误差。PCA 的目标是：自动识别数据内在的低维线性子空间，并将数据投影到该子空间上，实现降维、压缩与去噪。

一、数据预处理：中心化与归一化

在执行 PCA 之前，必须进行特定的数据预处理。将数据平移，使样本均值落在原点：

x(i)←x(i)−μ,μ=1n∑i=1nx(i)x^{(i)} \leftarrow x^{(i)} - \mu, \qquad \mu = \frac{1}{n}\sum_{i=1}^{n} x^{(i)} x(i)←x(i)−μ,μ=n1​i=1∑n​x(i)

为什么必须做？ 如果不减去均值，PCA 算出的"最大方差方向"会指向簇中心的方向，而非数据延展的方向。这会导致完全错误的特征向量。

将每个特征除以其标准差，使各特征处于同一尺度：

x~j(i)=xj(i)σj,σj2=1n∑i=1n(xj(i)−μj)2\tilde{x}_j^{(i)} = \frac{x_j^{(i)}}{\sigma_j}, \qquad \sigma_j^2 = \frac{1}{n}\sum_{i=1}^{n} (x_j^{(i)} - \mu_j)^2 x~j(i)​=σj​xj(i)​​,σj2​=n1​i=1∑n​(xj(i)​−μj​)2

为什么必须做？ 数值大的特征（如英尺，数值上千）会直接垄断方差目标，使 PCA 忽略数值小但更具判别力的特征（如英里）。

注意：本笔记后续所有推导，默认数据已完成中心化与归一化，即 E[x]=0\mathbb{E}[x]=0E[x]=0，且各特征方差为 111。

二、几何直觉

PCA 有两个完全等价的几何解释。

视角 A：最大化投影方差（Maximize Variance） 。寻找一个单位方向 u∈Rdu \in \mathbb{R}^du∈Rd（∥u∥=1\|u\|=1∥u∥=1），使得所有数据点投影到该方向后的方差最大。直觉上，这就是穿过椭圆形数据云最长的那条轴。

视角 B：最小化重构误差 / 残差（Minimize Residuals） 。寻找一条过原点的直线（子空间），使得所有数据点到该直线的垂直距离（残差）平方和最小。

结论：最大化投影方差 ⟺\Longleftrightarrow⟺ 最小化垂直残差。它们是同一优化问题的两种等价表述，下文将通过线性代数严格证明。

设中心化后的数据矩阵为 X∈Rn×dX \in \mathbb{R}^{n \times d}X∈Rn×d（nnn 个样本，ddd 个特征）。设目标投影方向为单位向量 u∈Rdu \in \mathbb{R}^du∈Rd，满足 uTu=1u^T u = 1uTu=1。

视角 A 的代数形式：数据在 uuu 上的投影值为 Xu∈RnX u \in \mathbb{R}^nXu∈Rn（nnn 个标量）。投影方差（忽略 1/n1/n1/n 常数）为：

Varproj=∑i=1n(xiTu)2=(Xu)T(Xu)=uT(XTX)u\text{Var}_{\text{proj}} = \sum_{i=1}^n (x_i^T u)^2 = (X u)^T (X u) = u^T (X^T X) u Varproj​=i=1∑n​(xiT​u)2=(Xu)T(Xu)=uT(XTX)u

其中 A=XTXA = X^T XA=XTX 是（未除 nnn 的）协方差矩阵（因已中心化）。优化问题写为：

max⁡uuTAus.t.uTu=1(1)\max_{u} \quad u^T A u \quad \text{s.t.} \quad u^T u = 1 \tag{1} umax​uTAus.t.uTu=1(1)

视角 B 的代数形式：投影矩阵为 P=uuTP = u u^TP=uuT。投影后的数据为 XP=XuuTX P = X u u^TXP=XuuT。残差矩阵为 X−XuuTX - X u u^TX−XuuT，其残差平方和为 Frobenius 范数的平方：

Residual=∥X−XuuT∥F2\text{Residual} = \| X - X u u^T \|_F^2 Residual=∥X−XuuT∥F2​

优化问题写为：

min⁡u∥X−XuuT∥F2s.t.uTu=1(2)\min_{u} \quad \| X - X u u^T \|_F^2 \quad \text{s.t.} \quad u^T u = 1 \tag{2} umin​∥X−XuuT∥F2​s.t.uTu=1(2)

核心推导：证明两个视角等价。展开视角 B 的残差项（利用迹 tr\text{tr}tr 的循环性质 tr(AB)=tr(BA)\text{tr}(AB)=\text{tr}(BA)tr(AB)=tr(BA)）：

∥X−XuuT∥F2=tr((X−XuuT)T(X−XuuT))=tr(XTX)−tr(uuTXTX)−tr(XTXuuT)+tr(uuTXTXuuT)=tr(XTX)−uT(XTX)u\begin{aligned} \| X - X u u^T \|_F^2 &= \text{tr}\left( (X - X u u^T)^T (X - X u u^T) \right) \\ &= \text{tr}(X^T X) - \text{tr}(u u^T X^T X) - \text{tr}(X^T X u u^T) + \text{tr}(u u^T X^T X u u^T) \\ &= \text{tr}(X^T X) - u^T (X^T X) u \end{aligned} ∥X−XuuT∥F2​​=tr((X−XuuT)T(X−XuuT))=tr(XTX)−tr(uuTXTX)−tr(XTXuuT)+tr(uuTXTXuuT)=tr(XTX)−uT(XTX)u​

因为 tr(XTX)=∑i,jXij2\text{tr}(X^T X) = \sum_{i,j} X_{ij}^2tr(XTX)=∑i,j​Xij2​ 是数据总能量（常数，与 uuu 无关），所以：

min⁡u(常数−uTAu)⟺max⁡u(uTAu)\min_u \big( \text{常数} - u^T A u \big) \quad \Longleftrightarrow \quad \max_u \big( u^T A u \big) umin​(常数−uTAu)⟺umax​(uTAu)

两个视角严格等价，统一为同一个优化问题：

u1=arg⁡max⁡uTu=1uT(XTX)u(3)\boxed{ u_1 = \arg\max_{u^T u = 1} u^T (X^T X) u } \tag{3} u1​=arguTu=1max​uT(XTX)u​(3)

如何求解优化问题 (3) 中的 uuu？引入拉格朗日乘子 λ\lambdaλ：

L(u,λ)=uTAu−λ(uTu−1)\mathcal{L}(u, \lambda) = u^T A u - \lambda (u^T u - 1) L(u,λ)=uTAu−λ(uTu−1)

对 uuu 求梯度并令其为零：

∂L∂u=2Au−2λu=0⟹Au=λu(4)\frac{\partial \mathcal{L}}{\partial u} = 2 A u - 2 \lambda u = 0 \quad \Longrightarrow \quad \boxed{ A u = \lambda u } \tag{4} ∂u∂L​=2Au−2λu=0⟹Au=λu​(4)

解 uuu 是矩阵 AAA 的特征向量（Eigenvector），对应的 λ\lambdaλ 是特征值（Eigenvalue）。将 (4) 代回目标函数 (3)：

uTAu=uT(λu)=λ(uTu)=λu^T A u = u^T (\lambda u) = \lambda (u^T u) = \lambda uTAu=uT(λu)=λ(uTu)=λ

优化问题的最大值，恰好等于矩阵 AAA 的最大特征值 λmax⁡\lambda_{\max}λmax​；使该式成立的 uuu，就是最大特征值对应的特征向量 umax⁡u_{\max}umax​。

因为 A=XTXA = X^T XA=XTX 是实对称矩阵，根据线性代数中的谱定理（Spectral Theorem），它一定能被正交对角化：

A=UΛUT(5)\boxed{ A = U \Lambda U^T } \tag{5} A=UΛUT​(5)

其中 U=[u1,u2,…,ud]U = [u_1, u_2, \dots, u_d]U=[u1​,u2​,…,ud​] 是标准正交矩阵（UTU=IU^T U = IUTU=I），列向量 uiu_iui​ 是特征向量；Λ=diag(λ1,λ2,…,λd)\Lambda = \text{diag}(\lambda_1, \lambda_2, \dots, \lambda_d)Λ=diag(λ1​,λ2​,…,λd​) 是对角矩阵，且按惯例 λ1≥λ2≥⋯≥λd\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_dλ1​≥λ2​≥⋯≥λd​。

由此，特征向量 uiu_iui​ 是第 iii 个主成分方向（数据的第 iii 大变异方向），特征值 λi\lambda_iλi​ 是数据沿 uiu_iui​ 方向的方差大小；λ1\lambda_1λ1​ 是第一主成分解释的方差（最大），λ2\lambda_2λ2​ 是第二主成分解释的方差（次大）。

三、算法流程

高效计算解释方差。在实际应用中，我们常常关心"前 kkk 个主成分解释了多少数据"。因为矩阵的迹等于特征值之和：

∑j=1dλj=tr(A)=tr(XTX)=∑i=1n∥x(i)∥2(数据总方差)\sum_{j=1}^d \lambda_j = \text{tr}(A) = \text{tr}(X^T X) = \sum_{i=1}^n \|x^{(i)}\|^2 \quad (\text{数据总方差}) j=1∑d​λj​=tr(A)=tr(XTX)=i=1∑n​∥x(i)∥2(数据总方差)

因此，前 kkk 个主成分解释的方差比例可以计算为：

Explained Ratio=∑j=1kλj∑j=1dλj(6)\boxed{ \text{Explained Ratio} = \frac{\sum_{j=1}^k \lambda_j}{\sum_{j=1}^d \lambda_j} } \tag{6} Explained Ratio=∑j=1d​λj​∑j=1k​λj​​​(6)

这无需重新遍历数据，直接读取特征值即可。

PCA 完整算法步骤：

  1. 预处理：中心化（减去均值），并按特征方差归一化。
  2. 计算协方差矩阵：A=XTXA = X^T XA=XTX（或除以 nnn，不影响特征向量）。
  3. 特征分解：求解 AAA 的特征值 λi\lambda_iλi​ 与特征向量 uiu_iui​，并按 λ\lambdaλ 降序排列。
  4. 选择子空间：取前 kkk 个特征向量组成投影矩阵 Uk=[u1,…,uk]U_k = [u_1, \dots, u_k]Uk​=[u1​,…,uk​]。
  5. 降维投影：Y=XUkY = X U_kY=XUk​，得到降维后的数据（每个样本变为 kkk 维）。

四、矩阵秩、Eckart-Young 定理与 SVD 实现

回到开篇的"冗余特征"问题：若数据存在完美线性相关，则 rank(XTX)<d\text{rank}(X^T X) < drank(XTX)<d，零特征值对应的特征向量就是冗余方向。实际数据中，PCA 通过特征值截断（舍弃小特征值），本质上是在做低秩矩阵近似（Low-rank Approximation）。根据 Eckart-Young 定理，PCA 给出的 Y=XUkY = X U_kY=XUk​ 是 XXX 在 Frobenius 范数意义下的最优 kkk 秩近似。这就是为什么 PCA 能同时完成降维、压缩和去噪。

在实际计算中，我们从不直接对 XTXX^T XXTX 做特征分解，因为这涉及到平方运算，会极大恶化矩阵的条件数（Condition Number），导致数值精度丢失。真正的工业级实现依赖 奇异值分解（Singular Value Decomposition, SVD） 。对数据矩阵 X∈Rn×dX \in \mathbb{R}^{n \times d}X∈Rn×d（通常 n≫dn \gg dn≫d）做"瘦 SVD"（Thin SVD）：

X=USVTX = U S V^T X=USVT

其中 U∈Rn×dU \in \mathbb{R}^{n \times d}U∈Rn×d 是左奇异向量矩阵（UTU=IU^T U = IUTU=I），S=diag(s1,s2,…,sd)S = \text{diag}(s_1, s_2, \dots, s_d)S=diag(s1​,s2​,…,sd​) 是对角奇异值矩阵（s1≥s2≥⋯≥sds_1 \ge s_2 \ge \dots \ge s_ds1​≥s2​≥⋯≥sd​），V∈Rd×dV \in \mathbb{R}^{d \times d}V∈Rd×d 是右奇异向量矩阵（VTV=IV^T V = IVTV=I）。由此计算协方差矩阵：

XTX=(USVT)T(USVT)=VSTUTUSVT=VS2VTX^T X = (U S V^T)^T (U S V^T) = V S^T U^T U S V^T = V S^2 V^T XTX=(USVT)T(USVT)=VSTUTUSVT=VS2VT

对比谱分解 XTX=VΛVTX^T X = V \Lambda V^TXTX=VΛVT，我们发现：右奇异向量矩阵 VVV 恰好就是主成分矩阵（特征向量），奇异值的平方 si2s_i^2si2​ 恰好就是特征值 λi\lambda_iλi​（解释方差）。SVD 直接作用于原始矩阵 XXX，避免了计算 XTXX^T XXTX 带来的平方损失和数值溢出风险，且能同时处理矩形矩阵（当 n<dn < dn<d 时依然成立），是 NumPy 和 PyTorch 等库的标准底层实现。
