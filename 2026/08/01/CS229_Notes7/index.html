一、K-means 聚类算法

1.1 问题设定与符号

在无监督学习中，我们仅有训练样本 {x(1),…,x(n)}\{x^{(1)}, \dots, x^{(n)}\}{x(1),…,x(n)}，没有对应的标签 yyy。我们的目标是将数据自动划分成若干个“簇”（cluster）。K-means 是最广泛使用的聚类算法之一，它试图找到数据中的自然分组。

  • 输入：簇的个数 kkk，样本集 {x(i)}i=1n\{x^{(i)}\}_{i=1}^n{x(i)}i=1n​，其中 x(i)∈Rdx^{(i)} \in \mathbb{R}^dx(i)∈Rd。
  • 输出：kkk 个簇中心 μ1,…,μk∈Rd\mu_1, \dots, \mu_k \in \mathbb{R}^dμ1​,…,μk​∈Rd，以及每个样本 x(i)x^{(i)}x(i) 的簇分配 c(i)∈{1,…,k}c^{(i)} \in \{1, \dots, k\}c(i)∈{1,…,k}。

1.2 算法步骤

  1. 初始化：随机选择 kkk 个训练样本作为初始簇中心 μ1,…,μk\mu_1, \dots, \mu_kμ1​,…,μk​。也可以使用其他初始化方法，但通常从训练集中随机选取是常见做法。

  2. 重复直至收敛：

    (i) 分配步骤：对每个样本 iii，将其分配给最近的簇中心：

    c(i)←arg⁡min⁡j∥x(i)−μj∥2c^{(i)} \leftarrow \arg\min_j \|x^{(i)} - \mu_j\|^2 c(i)←argjmin​∥x(i)−μj​∥2

    (ii) 更新步骤：对每个簇 jjj，重新计算簇中心为该簇所有样本的均值：

    μj←∑i=1n1{c(i)=j} x(i)∑i=1n1{c(i)=j}\mu_j \leftarrow \frac{\sum_{i=1}^n \mathbf{1}\{c^{(i)} = j\} \, x^{(i)}}{\sum_{i=1}^n \mathbf{1}\{c^{(i)} = j\}} μj​←∑i=1n​1{c(i)=j}∑i=1n​1{c(i)=j}x(i)​

1.3 收敛性分析

为了分析 K-means 的收敛性，我们定义distortion function：

J(c,μ)=∑i=1n∥x(i)−μc(i)∥2J(c, \mu) = \sum_{i=1}^n \|x^{(i)} - \mu_{c^{(i)}}\|^2 J(c,μ)=i=1∑n​∥x(i)−μc(i)​∥2

该函数衡量每个样本与其分配到的簇中心的距离平方和。我们的目标是最小化 JJJ。

K-means 算法本质上是对 JJJ 的坐标下降法（coordinate descent）：

  • 分配步骤：固定 μ\muμ，对每个 c(i)c^{(i)}c(i) 分别最小化 JJJ。因为 c(i)c^{(i)}c(i) 只出现在 ∥x(i)−μc(i)∥2\|x^{(i)} - \mu_{c^{(i)}}\|^2∥x(i)−μc(i)​∥2 这一项中，所以独立地选择最近的 μj\mu_jμj​ 即可最小化每一项，从而最小化整个 JJJ。因此这一步 JJJ 不增加。

  • 更新步骤：固定 ccc，对每个 μj\mu_jμj​ 求导并令其为零。由于 JJJ 对每个 μj\mu_jμj​ 是凸二次函数，其最小值点就是该簇内所有样本的均值：

    ∂J∂μj=∑i:c(i)=j2(μj−x(i))=0  ⟹  μj=∑i:c(i)=jx(i)∑i:c(i)=j1\frac{\partial J}{\partial \mu_j} = \sum_{i:c^{(i)}=j} 2(\mu_j - x^{(i)}) = 0 \implies \mu_j = \frac{\sum_{i:c^{(i)}=j} x^{(i)}}{\sum_{i:c^{(i)}=j} 1} ∂μj​∂J​=i:c(i)=j∑​2(μj​−x(i))=0⟹μj​=∑i:c(i)=j​1∑i:c(i)=j​x(i)​

    因此更新步骤也最小化 JJJ。

因此每一轮迭代 JJJ 单调递减，且 J≥0J \ge 0J≥0（距离平方和始终非负），所以算法必定收敛（到局部极小值或鞍点）。

JJJ 是非凸函数，K-means 容易陷入局部最优。常用的缓解方法是多次随机初始化，然后选择畸变最小的结果作为最终聚类。

二、EM 算法

EM（Expectation-Maximization）算法是一类用于含隐变量（latent variables）的概率模型进行极大似然估计的通用方法。

2.1 混合高斯模型

假设数据由 kkk 个高斯分布混合生成。每个观测样本 x(i)x^{(i)}x(i) 对应一个隐变量 z(i)∈{1,…,k}z^{(i)} \in \{1, \dots, k\}z(i)∈{1,…,k}，表示它来自哪个高斯分量。

模型参数：

  • ϕj=p(z(i)=j)\phi_j = p(z^{(i)} = j)ϕj​=p(z(i)=j)（混合系数），满足 ϕj≥0\phi_j \ge 0ϕj​≥0，∑j=1kϕj=1\sum_{j=1}^k \phi_j = 1∑j=1k​ϕj​=1。
  • 每个分量 jjj 的均值 μj∈Rd\mu_j \in \mathbb{R}^dμj​∈Rd 和协方差矩阵 Σj\Sigma_jΣj​（对称正定）。

生成过程可描述为：

z(i)∼Multinomial(ϕ),x(i)∣z(i)=j∼N(μj,Σj)z^{(i)} \sim \text{Multinomial}(\phi),\qquad x^{(i)} \mid z^{(i)} = j \sim \mathcal{N}(\mu_j, \Sigma_j) z(i)∼Multinomial(ϕ),x(i)∣z(i)=j∼N(μj​,Σj​)

即先以概率 ϕj\phi_jϕj​ 选择第 jjj 个高斯分量，再从该高斯分布中采样得到 x(i)x^{(i)}x(i)。

对数似然为：

ℓ(ϕ,μ,Σ)=∑i=1nlog⁡p(x(i);ϕ,μ,Σ)=∑i=1nlog⁡∑j=1kp(x(i)∣z(i)=j;μ,Σ) p(z(i)=j;ϕ)\ell(\phi, \mu, \Sigma) = \sum_{i=1}^n \log p(x^{(i)}; \phi, \mu, \Sigma) = \sum_{i=1}^n \log \sum_{j=1}^k p(x^{(i)} \mid z^{(i)} = j; \mu, \Sigma) \, p(z^{(i)} = j; \phi) ℓ(ϕ,μ,Σ)=i=1∑n​logp(x(i);ϕ,μ,Σ)=i=1∑n​logj=1∑k​p(x(i)∣z(i)=j;μ,Σ)p(z(i)=j;ϕ)

由于对数函数内部包含求和，直接最大化此似然很困难——对参数求导后得到的方程没有闭式解。（讲义中建议读者亲自尝试推导以验证这一点。）

但如果隐变量 z(i)z^{(i)}z(i) 已知，则极大似然估计非常容易。此时对数似然为：

ℓ(ϕ,μ,Σ)=∑i=1nlog⁡p(x(i)∣z(i);μ,Σ)+log⁡p(z(i);ϕ)\ell(\phi, \mu, \Sigma) = \sum_{i=1}^n \log p(x^{(i)} \mid z^{(i)}; \mu, \Sigma) + \log p(z^{(i)}; \phi) ℓ(ϕ,μ,Σ)=i=1∑n​logp(x(i)∣z(i);μ,Σ)+logp(z(i);ϕ)

对 ϕ,μ,Σ\phi, \mu, \Sigmaϕ,μ,Σ 分别求导可得闭式解：

ϕj=1n∑i=1n1{z(i)=j}\phi_j = \frac{1}{n} \sum_{i=1}^n \mathbf{1}\{z^{(i)} = j\} ϕj​=n1​i=1∑n​1{z(i)=j}

μj=∑i=1n1{z(i)=j}x(i)∑i=1n1{z(i)=j}\mu_j = \frac{\sum_{i=1}^n \mathbf{1}\{z^{(i)} = j\} x^{(i)}}{\sum_{i=1}^n \mathbf{1}\{z^{(i)} = j\}} μj​=∑i=1n​1{z(i)=j}∑i=1n​1{z(i)=j}x(i)​

Σj=∑i=1n1{z(i)=j}(x(i)−μj)(x(i)−μj)⊤∑i=1n1{z(i)=j}\Sigma_j = \frac{\sum_{i=1}^n \mathbf{1}\{z^{(i)} = j\} (x^{(i)} - \mu_j)(x^{(i)} - \mu_j)^\top}{\sum_{i=1}^n \mathbf{1}\{z^{(i)} = j\}} Σj​=∑i=1n​1{z(i)=j}∑i=1n​1{z(i)=j}(x(i)−μj​)(x(i)−μj​)⊤​

这与高斯判别分析中的参数估计几乎完全相同，只是这里的 z(i)z^{(i)}z(i) 起到了类别标签的作用。

然而在无监督学习中，z(i)z^{(i)}z(i) 是未知的隐变量。EM 算法正是为解决这类问题而设计的。

2.2 EM 算法在 GMM 上的应用

EM 算法迭代执行以下两步：

E 步（Expectation，期望步骤）：根据当前参数，计算每个隐变量的后验概率（称为“软”分配）：

wj(i)=p(z(i)=j∣x(i);ϕ,μ,Σ)=p(x(i)∣z(i)=j;μ,Σ) ϕj∑l=1kp(x(i)∣z(i)=l;μ,Σ) ϕlw_j^{(i)} = p(z^{(i)} = j \mid x^{(i)}; \phi, \mu, \Sigma) = \frac{p(x^{(i)} \mid z^{(i)} = j; \mu, \Sigma) \, \phi_j}{\sum_{l=1}^k p(x^{(i)} \mid z^{(i)} = l; \mu, \Sigma) \, \phi_l} wj(i)​=p(z(i)=j∣x(i);ϕ,μ,Σ)=∑l=1k​p(x(i)∣z(i)=l;μ,Σ)ϕl​p(x(i)∣z(i)=j;μ,Σ)ϕj​​

其中 p(x(i)∣z(i)=j;μ,Σ)p(x^{(i)} \mid z^{(i)} = j; \mu, \Sigma)p(x(i)∣z(i)=j;μ,Σ) 是在 x(i)x^{(i)}x(i) 处评估的、均值为 μj\mu_jμj​、协方差为 Σj\Sigma_jΣj​ 的高斯密度函数值；p(z(i)=j;ϕ)p(z^{(i)} = j; \phi)p(z(i)=j;ϕ) 就是 ϕj\phi_jϕj​。

这些权重 wj(i)w_j^{(i)}wj(i)​ 表示样本 iii 属于第 jjj 个分组的概率，它们是“软”的而不是“硬”的（0 或 1）。

M 步（Maximization，最大化步骤）：使用“软”分配权重更新参数，公式与隐变量已知时几乎完全相同，只是将指示函数 1{z(i)=j}\mathbf{1}\{z^{(i)}=j\}1{z(i)=j} 换成了软权重 wj(i)w_j^{(i)}wj(i)​：

ϕj←1n∑i=1nwj(i)\phi_j \leftarrow \frac{1}{n} \sum_{i=1}^n w_j^{(i)} ϕj​←n1​i=1∑n​wj(i)​

μj←∑i=1nwj(i)x(i)∑i=1nwj(i)\mu_j \leftarrow \frac{\sum_{i=1}^n w_j^{(i)} x^{(i)}}{\sum_{i=1}^n w_j^{(i)}} μj​←∑i=1n​wj(i)​∑i=1n​wj(i)​x(i)​

Σj←∑i=1nwj(i)(x(i)−μj)(x(i)−μj)⊤∑i=1nwj(i)\Sigma_j \leftarrow \frac{\sum_{i=1}^n w_j^{(i)} (x^{(i)} - \mu_j)(x^{(i)} - \mu_j)^\top}{\sum_{i=1}^n w_j^{(i)}} Σj​←∑i=1n​wj(i)​∑i=1n​wj(i)​(x(i)−μj​)(x(i)−μj​)⊤​

对比 K-means：K-means 是“硬”分配（每个样本完全属于一个簇），而 EM 给出“软”分配（概率权重）。因此 EM 可视为 K-means 的概率版本。同样，EM 也受局部最优影响，需要多次初始化。

三、Jensen 不等式

设 fff 为凸函数（即 f′′(x)≥0f''(x) \ge 0f′′(x)≥0 对所有 x∈Rx \in \mathbb{R}x∈R 成立）。当 fff 接受向量输入时，这推广为 Hessian 矩阵半正定（H≥0H \ge 0H≥0）。如果 f′′(x)>0f''(x) > 0f′′(x)>0 对所有 xxx 成立，则称 fff 严格凸（向量情形为 Hessian 正定，H>0H > 0H>0）。

定理（Jensen 不等式）：设 fff 为凸函数，XXX 为随机变量，则：

E[f(X)]≥f(E[X])\mathbb{E}[f(X)] \ge f(\mathbb{E}[X]) E[f(X)]≥f(E[X])

若 fff 严格凸，等号成立当且仅当 XXX 几乎处处为常数（即 X=E[X]X = \mathbb{E}[X]X=E[X] 以概率 1 成立）。

注：fff 为[严格]凹函数当且仅当 −f-f−f 为[严格]凸函数（即 f′′(x)≤0f''(x) \le 0f′′(x)≤0 或 H≤0H \le 0H≤0）。Jensen 不等式对于凹函数也成立，但不等式方向相反：E[f(X)]≤f(E[X])\mathbb{E}[f(X)] \le f(\mathbb{E}[X])E[f(X)]≤f(E[X])。

我们将使用 log⁡\loglog 函数（它是凹函数）来构造对数似然的下界。

四、通用 EM 算法

4.1 问题形式与基本思路

假设我们有一个含隐变量的概率模型 p(x,z;θ)p(x, z; \theta)p(x,z;θ)，其中 zzz 为离散隐变量（为简化，我们假设它取有限个值）。观测数据的边际似然为对隐变量求和得到：

ℓ(θ)=∑i=1nlog⁡p(x(i);θ)(11.2)\ell(\theta) = \sum_{i=1}^n \log p(x^{(i)}; \theta) \tag{11.2} ℓ(θ)=i=1∑n​logp(x(i);θ)(11.2)

但直接最大化 ℓ(θ)\ell(\theta)ℓ(θ) 可能很困难，因为这会导致难以处理的非凸优化问题。然而，如果隐变量 z(i)z^{(i)}z(i) 已知，极大似然估计通常是容易的。

在这样的设定下，EM 算法提供了一种高效的极大似然估计方法。我们的策略是反复构造 ℓ\ellℓ 的下界（E 步），然后优化这个下界（M 步）。

讲义中指出，求和 ∑i=1n\sum_{i=1}^n∑i=1n​ 在这里不是本质性的。为了简化 EM 算法的推导，我们首先考虑对单个样本 xxx 优化似然 log⁡p(x)\log p(x)logp(x)。推导出单样本的算法后，我们通过在所有相关方程中添加求和符号来推广到 nnn 个样本。

现在我们目标优化 log⁡p(x;θ)\log p(x; \theta)logp(x;θ)，它可以重写为：

4.3 使 ELBO 紧致：最优 QQQ 的选择

为了使下界在某个特定的 θ\thetaθ 值处紧致，我们需要上述推导中使用 Jensen 不等式的步骤以等号成立。对于严格凹的 log⁡\loglog 函数，等号成立当且仅当期望中涉及的随机变量是常数，即：

p(x,z;θ)Q(z)=c\frac{p(x, z; \theta)}{Q(z)} = c Q(z)p(x,z;θ)​=c

4.4 ELBO 的定义

五、ELBO 的几种解释

让我们更深入地理解 ELBO。定义 ELBO(x;Q,θ)=∑zQ(z)log⁡p(x,z;θ)Q(z)\text{ELBO}(x; Q, \theta) = \sum_z Q(z) \log \frac{p(x, z; \theta)}{Q(z)}ELBO(x;Q,θ)=∑z​Q(z)logQ(z)p(x,z;θ)​。它可以写成几种等价形式。

首先：

ELBO(x;Q,θ)=Ez∼Q[log⁡p(x,z;θ)]−Ez∼Q[log⁡Q(z)]\text{ELBO}(x; Q, \theta) = \mathbb{E}_{z \sim Q}[\log p(x, z; \theta)] - \mathbb{E}_{z \sim Q}[\log Q(z)] ELBO(x;Q,θ)=Ez∼Q​[logp(x,z;θ)]−Ez∼Q​[logQ(z)]

其次，它可以分解为：

ELBO(x;Q,θ)=Ez∼Q[log⁡p(x∣z;θ)]−DKL(Q∥pz)(11.15)\text{ELBO}(x; Q, \theta) = \mathbb{E}_{z \sim Q}[\log p(x \mid z; \theta)] - D_{KL}(Q \| p_z) \tag{11.15} ELBO(x;Q,θ)=Ez∼Q​[logp(x∣z;θ)]−DKL​(Q∥pz​)(11.15)

其中 pzp_zpz​ 表示 zzz 的边际分布（在分布 p(x,z;θ)p(x, z; \theta)p(x,z;θ) 下），DKLD_{KL}DKL​ 表示 KL 散度：

DKL(Q∥pz)=∑zQ(z)log⁡Q(z)p(z)(11.16)D_{KL}(Q \| p_z) = \sum_z Q(z) \log \frac{Q(z)}{p(z)} \tag{11.16} DKL​(Q∥pz​)=z∑​Q(z)logp(z)Q(z)​(11.16)

在很多情况下，zzz 的边际分布不依赖于参数 θ\thetaθ。此时，关于 θ\thetaθ 最大化 ELBO 等价于最大化 (11.15) 中的第一项。这对应于最大化 xxx 在给定 zzz 下的条件似然，通常比原始问题更简单。

ELBO 的另一种形式是：

ELBO(x;Q,θ)=log⁡p(x;θ)−DKL(Q∥pz∣x)(11.17)\text{ELBO}(x; Q, \theta) = \log p(x; \theta) - D_{KL}(Q \| p_{z \mid x}) \tag{11.17} ELBO(x;Q,θ)=logp(x;θ)−DKL​(Q∥pz∣x​)(11.17)

其中 pz∣xp_{z \mid x}pz∣x​ 是 zzz 在给定 xxx 和参数 θ\thetaθ 下的条件分布。这个形式清楚地表明：关于 QQQ 最大化 ELBO 等价于最小化 QQQ 与后验 pz∣xp_{z \mid x}pz∣x​ 之间的 KL 散度，因此最大值在 Q=pz∣xQ = p_{z \mid x}Q=pz∣x​ 处取得，这与我们之前在 (11.8) 中的结论一致。

在混合高斯模型中，对于每个固定的 θ\thetaθ，QQQ 的最优选择 Q(z)=p(z∣x;θ)Q(z) = p(z \mid x; \theta)Q(z)=p(z∣x;θ)（即 zzz 的后验分布）可以解析计算。但在许多更复杂的模型中（例如由神经网络参数化的生成模型），计算精确的后验分布 p(z∣x;θ)p(z \mid x; \theta)p(z∣x;θ) 是不可行的（intractable）。

7.2 连续隐变量的挑战

当 z∈Rkz \in \mathbb{R}^kz∈Rk 是连续隐变量时，为了成功优化 (11.20)，我们需要做出几个决策。首先，我们需要给出分布 QiQ_iQi​ 的简洁表示，因为它是在无限多个点上的分布。一个自然的选择是假设 QiQ_iQi​ 是一个具有某些均值和方差的高斯分布。

我们还需要更简洁地表示所有样本的 QiQ_iQi​ 的均值。注意 Qi(z(i))Q_i(z^{(i)})Qi​(z(i)) 应该近似 p(z(i)∣x(i);θ)p(z^{(i)} \mid x^{(i)}; \theta)p(z(i)∣x(i);θ)。让所有 QiQ_iQi​ 的均值是 x(i)x^{(i)}x(i) 的某个函数是合理的。
