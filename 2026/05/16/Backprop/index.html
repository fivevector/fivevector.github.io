Backprop and Two-Layer Networks

This article is based on the CS231n course materials and assignment1.

Backpropagation

Backpropagation is a fundamental algorithm used in training neural networks. It allows us to compute the gradients of the loss function with respect to the weights and biases of the network efficiently. The key idea behind backpropagation is to apply the chain rule of calculus to propagate the error backward through the network.

Affine Layer

Forward Pass

Assume the relationship between the input and output in the forward pass is given by the linear transformation (Affine layer):

Y=XW+bY = XW + b Y=XW+b

The dimensions and element indexing for each matrix are defined as follows:

  • Input Matrix XXX: Shape (N,D)(N, D)(N,D), where the element in the iii-th row and jjj-th column is denoted as XijX_{ij}Xij​.

  • Weight Matrix WWW: Shape (D,M)(D, M)(D,M), where the element in the jjj-th row and kkk-th column is denoted as WjkW_{jk}Wjk​.

  • Bias Vector bbb: Shape (M,)(M,)(M,). Its kkk-th element is denoted as bkb_kbk​. In matrix addition, it is replicated across all rows via broadcasting.

  • Output Matrix YYY: Shape (N,M)(N, M)(N,M), where the element in the iii-th row and kkk-th column is denoted as YikY_{ik}Yik​.

According to the definition of matrix multiplication, the scalar formula for computing each individual element YikY_{ik}Yik​ is:

Yik=∑j=1DXijWjk+bkY_{ik} = \sum_{j=1}^{D} X_{ij} W_{jk} + b_k Yik​=j=1∑D​Xij​Wjk​+bk​

During backpropagation, we assume that the upstream layer has already passed down the gradient of the loss function LLL with respect to the current output YYY, denoted as ∂L∂Y\frac{\partial L}{\partial Y}∂Y∂L​ (commonly written as doutdoutdout or dydydy in code), which also has a shape of (N,M)(N, M)(N,M). Our objective is to determine:

∂L∂X∈RN×D,∂L∂W∈RD×M,∂L∂b∈RM\frac{\partial L}{\partial X} \in \mathbb{R}^{N \times D}, \quad \frac{\partial L}{\partial W} \in \mathbb{R}^{D \times M}, \quad \frac{\partial L}{\partial b} \in \mathbb{R}^{M} ∂X∂L​∈RN×D,∂W∂L​∈RD×M,∂b∂L​∈RM

Backward Pass

We wish to compute the partial derivative of the loss LLL with respect to a specific element WjkW_{jk}Wjk​ in the weight matrix. Using the multivariate chain rule, since WjkW_{jk}Wjk​ affects all elements in the kkk-th column of the output matrix YYY (namely Y1k,Y2k,…,YNkY_{1k}, Y_{2k}, \dots, Y_{Nk}Y1k​,Y2k​,…,YNk​), we must sum over all paths affected by this element:

∂L∂Wjk=∑i=1N∂L∂Yik∂Yik∂Wjk\frac{\partial L}{\partial W_{jk}} = \sum_{i=1}^{N} \frac{\partial L}{\partial Y_{ik}} \frac{\partial Y_{ik}}{\partial W_{jk}} ∂Wjk​∂L​=i=1∑N​∂Yik​∂L​∂Wjk​∂Yik​​

Recalling the forward propagation formula Yik=∑m=1DXimWmk+bkY_{ik} = \sum_{m=1}^{D} X_{im} W_{mk} + b_kYik​=∑m=1D​Xim​Wmk​+bk​, we take its partial derivative with respect to WjkW_{jk}Wjk​:

∂Yik∂Wjk=Xij\frac{\partial Y_{ik}}{\partial W_{jk}} = X_{ij} ∂Wjk​∂Yik​​=Xij​

Substituting this back into the chain rule formula yields:

∂L∂Wjk=∑i=1N∂L∂YikXij=∑i=1NXij∂L∂Yik\frac{\partial L}{\partial W_{jk}} = \sum_{i=1}^{N} \frac{\partial L}{\partial Y_{ik}} X_{ij} = \sum_{i=1}^{N} X_{ij} \frac{\partial L}{\partial Y_{ik}} ∂Wjk​∂L​=i=1∑N​∂Yik​∂L​Xij​=i=1∑N​Xij​∂Yik​∂L​

Observing the expression above, ∑i=1NXij∂L∂Yik\sum_{i=1}^{N} X_{ij} \frac{\partial L}{\partial Y_{ik}}∑i=1N​Xij​∂Yik​∂L​ is precisely the dot product between the jjj-th column of matrix XXX and the kkk-th column of matrix ∂L∂Y\frac{\partial L}{\partial Y}∂Y∂L​. This perfectly maps to the product of the jjj-th row of XTX^TXT and the kkk-th column of ∂L∂Y\frac{\partial L}{\partial Y}∂Y∂L​ in standard matrix multiplication. Therefore:

∂L∂W=XT⋅∂L∂Y\frac{\partial L}{\partial W} = X^T \cdot \frac{\partial L}{\partial Y} ∂W∂L​=XT⋅∂Y∂L​

Similarly, we compute the partial derivative of the loss LLL with respect to a specific element XijX_{ij}Xij​ in the input matrix. Since XijX_{ij}Xij​ participates in the computation of every element in the iii-th row of the output matrix YYY (namely Yi1,Yi2,…,YiMY_{i1}, Y_{i2}, \dots, Y_{iM}Yi1​,Yi2​,…,YiM​), the chain rule is formulated as:

∂L∂Xij=∑k=1M∂L∂Yik∂Yik∂Xij\frac{\partial L}{\partial X_{ij}} = \sum_{k=1}^{M} \frac{\partial L}{\partial Y_{ik}} \frac{\partial Y_{ik}}{\partial X_{ij}} ∂Xij​∂L​=k=1∑M​∂Yik​∂L​∂Xij​∂Yik​​

Taking the partial derivative of YikY_{ik}Yik​ with respect to XijX_{ij}Xij​:

∂Yik∂Xij=Wjk\frac{\partial Y_{ik}}{\partial X_{ij}} = W_{jk} ∂Xij​∂Yik​​=Wjk​

Substituting this back into the chain rule formula yields:

∂L∂Xij=∑k=1M∂L∂YikWjk\frac{\partial L}{\partial X_{ij}} = \sum_{k=1}^{M} \frac{\partial L}{\partial Y_{ik}} W_{jk} ∂Xij​∂L​=k=1∑M​∂Yik​∂L​Wjk​

Observing the expression above, ∑k=1M∂L∂YikWjk\sum_{k=1}^{M} \frac{\partial L}{\partial Y_{ik}} W_{jk}∑k=1M​∂Yik​∂L​Wjk​ is exactly the dot product of the iii-th row of matrix ∂L∂Y\frac{\partial L}{\partial Y}∂Y∂L​ and the jjj-th row of the weight matrix WWW (which corresponds to the jjj-th column of WTW^TWT). Thus, combining these components into matrix form gives:

∂L∂X=∂L∂Y⋅WT\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y} \cdot W^T ∂X∂L​=∂Y∂L​⋅WT

We compute the partial derivative of the loss LLL with respect to the kkk-th element bkb_kbk​ of the bias vector. Due to the broadcasting mechanism, bkb_kbk​ influences the entire kkk-th column of the output matrix YYY (namely Y1k,Y2k,…,YNkY_{1k}, Y_{2k}, \dots, Y_{Nk}Y1k​,Y2k​,…,YNk​):

∂L∂bk=∑i=1N∂L∂Yik∂Yik∂bk\frac{\partial L}{\partial b_k} = \sum_{i=1}^{N} \frac{\partial L}{\partial Y_{ik}} \frac{\partial Y_{ik}}{\partial b_k} ∂bk​∂L​=i=1∑N​∂Yik​∂L​∂bk​∂Yik​​

Since ∂Yik∂bk=1\frac{\partial Y_{ik}}{\partial b_k} = 1∂bk​∂Yik​​=1, the equation simplifies to:

∂L∂bk=∑i=1N∂L∂Yik\frac{\partial L}{\partial b_k} = \sum_{i=1}^{N} \frac{\partial L}{\partial Y_{ik}} ∂bk​∂L​=i=1∑N​∂Yik​∂L​

This indicates that the gradient with respect to bkb_kbk​ is obtained by summing the upstream gradient matrix ∂L∂Y\frac{\partial L}{\partial Y}∂Y∂L​ along its columns (i.e., summing across all rows for each column):

∂L∂b=∑i=1N∂L∂Yi,:\frac{\partial L}{\partial b} = \sum_{i=1}^{N} \frac{\partial L}{\partial Y_{i, :}} ∂b∂L​=i=1∑N​∂Yi,:​∂L​

ReLU Layer

Forward Pass

The Rectified Linear Unit (ReLU) is one of the most commonly used activation functions in deep learning. It applies an element-wise maximum operation to its input:

A=max⁡(0,Z)A = \max(0, Z) A=max(0,Z)

The dimensions for each matrix are defined as follows:

  • Input Matrix ZZZ: Shape (N,M)(N, M)(N,M), representing the pre-activation linear combinations.
  • Output Matrix AAA: Shape (N,M)(N, M)(N,M), representing the activated features.

The scalar formula for computing each individual element AikA_{ik}Aik​ is:

Aik=max⁡(0,Zik)A_{ik} = \max(0, Z_{ik}) Aik​=max(0,Zik​)

During backpropagation, we assume the upstream layer has passed down the gradient ∂L∂A\frac{\partial L}{\partial A}∂A∂L​ (shape (N,M)(N, M)(N,M)). Our objective is to determine ∂L∂Z∈RN×M\frac{\partial L}{\partial Z} \in \mathbb{R}^{N \times M}∂Z∂L​∈RN×M.

Backward Pass

Since ReLU operates element-wise, the element ZikZ_{ik}Zik​ only affects the corresponding output element AikA_{ik}Aik​. Applying the chain rule to a single element yields:

∂L∂Zik=∂L∂Aik∂Aik∂Zik\frac{\partial L}{\partial Z_{ik}} = \frac{\partial L}{\partial A_{ik}} \frac{\partial A_{ik}}{\partial Z_{ik}} ∂Zik​∂L​=∂Aik​∂L​∂Zik​∂Aik​​

The derivative of the scalar ReLU function with respect to its input is a step function:

∂Aik∂Zik={1if Zik>00if Zik≤0\frac{\partial A_{ik}}{\partial Z_{ik}} = \begin{cases} 1 & \text{if } Z_{ik} > 0 \\ 0 & \text{if } Z_{ik} \le 0 \end{cases} ∂Zik​∂Aik​​={10​if Zik​>0if Zik​≤0​

Therefore, the backpropagation formula can be written in element-wise (Hadamard) product form (∘\circ∘):

∂L∂Z=∂L∂A∘1{Z>0}\frac{\partial L}{\partial Z} = \frac{\partial L}{\partial A} \circ \mathbf{1}\{Z > 0\} ∂Z∂L​=∂A∂L​∘1{Z>0}

Loss Layer: Softmax with Cross-Entropy

In the final layer NNN, we perform multiclass classification over KKK classes. Let YYY be the scores matrix of shape (N,K)(N, K)(N,K) before softmax, and ppp be the predicted probabilities:

pik=eYik∑j=1KeYijp_{ik} = \frac{e^{Y_{ik}}}{\sum_{j=1}^{K} e^{Y_{ij}}} pik​=∑j=1K​eYij​eYik​​

The Ground-Truth matrix TTT has a shape of (N,K)(N, K)(N,K), where Tij=1T_{ij} = 1Tij​=1 if the true label of example iii is jjj, and 000 otherwise. The total cross-entropy loss averaged over the minibatch of size NNN is:

L=−1N∑i=1N∑j=1KTijlog⁡pijL = -\frac{1}{N} \sum_{i=1}^{N} \sum_{j=1}^{K} T_{ij} \log p_{ij} L=−N1​i=1∑N​j=1∑K​Tij​logpij​

During backpropagation, we need to compute the gradient of the loss with respect to the input scores: ∂L∂Y∈RN×K\frac{\partial L}{\partial Y} \in \mathbb{R}^{N \times K}∂Y∂L​∈RN×K.

Backward Pass Derivation

Let’s focus on a single example iii (and omit the index iii for simplicity). The loss for one example is Li=−∑j=1KTjlog⁡pjL_i = -\sum_{j=1}^{K} T_{j} \log p_{j}Li​=−∑j=1K​Tj​logpj​. We want to find ∂Li∂Yk\frac{\partial L_i}{\partial Y_k}∂Yk​∂Li​​:

∂Li∂Yk=−∑j=1KTj∂log⁡pj∂Yk=−∑j=1KTjpj∂pj∂Yk\frac{\partial L_i}{\partial Y_k} = -\sum_{j=1}^{K} T_{j} \frac{\partial \log p_{j}}{\partial Y_k} = -\sum_{j=1}^{K} \frac{T_{j}}{p_{j}} \frac{\partial p_{j}}{\partial Y_k} ∂Yk​∂Li​​=−j=1∑K​Tj​∂Yk​∂logpj​​=−j=1∑K​pj​Tj​​∂Yk​∂pj​​

We need the derivative of the softmax output pjp_jpj​ with respect to the input score YkY_kYk​:

  • Case 1: j=kj = kj=k

∂pk∂Yk=eYk∑eY−eYkeYk(∑eY)2=pk(1−pk)\frac{\partial p_k}{\partial Y_k} = \frac{e^{Y_k} \sum e^{Y} - e^{Y_k} e^{Y_k}}{(\sum e^{Y})^2} = p_k(1 - p_k) ∂Yk​∂pk​​=(∑eY)2eYk​∑eY−eYk​eYk​​=pk​(1−pk​)

  • Case 2: j≠kj \neq kj=k

∂pj∂Yk=0−eYjeYk(∑eY)2=−pjpk\frac{\partial p_j}{\partial Y_k} = \frac{0 - e^{Y_j} e^{Y_k}}{(\sum e^{Y})^2} = -p_j p_k ∂Yk​∂pj​​=(∑eY)20−eYj​eYk​​=−pj​pk​

Substituting these back into the loss derivative:

∂Li∂Yk=−Tkpk⋅pk(1−pk)−∑j≠kTjpj⋅(−pjpk)\frac{\partial L_i}{\partial Y_k} = -\frac{T_k}{p_k} \cdot p_k(1 - p_k) - \sum_{j \neq k} \frac{T_j}{p_j} \cdot (-p_j p_k) ∂Yk​∂Li​​=−pk​Tk​​⋅pk​(1−pk​)−j=k∑​pj​Tj​​⋅(−pj​pk​)

∂Li∂Yk=−Tk(1−pk)+∑j≠kTjpk=−Tk+Tkpk+∑j≠kTjpk\frac{\partial L_i}{\partial Y_k} = -T_k(1 - p_k) + \sum_{j \neq k} T_j p_k = -T_k + T_k p_k + \sum_{j \neq k} T_j p_k ∂Yk​∂Li​​=−Tk​(1−pk​)+j=k∑​Tj​pk​=−Tk​+Tk​pk​+j=k∑​Tj​pk​

Since ∑j=1KTj=1\sum_{j=1}^{K} T_j = 1∑j=1K​Tj​=1 (one-hot vectors sum to 1), the expression simplifies elegantly to:

∂Li∂Yk=pk−Tk\frac{\partial L_i}{\partial Y_k} = p_k - T_k ∂Yk​∂Li​​=pk​−Tk​

Averaging over the minibatch of size NNN, the full matrix gradient is:

∂L∂Y=1N(P−T)\frac{\partial L}{\partial Y} = \frac{1}{N} (P - T) ∂Y∂L​=N1​(P−T)
