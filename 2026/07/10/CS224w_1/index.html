CS224w Notes 1 : Node Embedding

这个系列是本人学习CS224w的学习笔记。本文是第一篇文章，对应Slides 2。

图表示学习(Graph Representation Learning)的动机

在图上做预测的传统方法是手工提取节点、边或图的特征（如节点的度、聚类系数等），然后输入到SVM等分类器中。这种方法的问题是特征工程成本高、且针对特定任务，泛化能力差。而图表示学习的目标不再是手动设计特征，而是让模型自动从图数据中学习到有用的特征（即嵌入）。这些嵌入是任务无关的（task-independent），学好后可以用于节点分类、链接预测、社区检测等多种下游任务。

因此嵌入的目标就是将图中的每个节点映射到一个低维、稠密的嵌入空间（embedding space），节点嵌入向量之间的相似度（similarity）应该和节点在图中的相似度相应。

这类似于Word2Vec将语义相似的词映射到向量空间中的相近位置。在这里，我们希望“结构位置”或“连接关系”相似的节点在向量空间中也彼此靠近。

节点嵌入的框架

我们初始获得一张图 G=(V,E)G = (V, E)G=(V,E)，VVV 是节点集合，AAA 是邻接矩阵。

编码器（Encoder）

ENC是一个函数，将每个节点 vvv 映射为一个低维的嵌入向量 zvz_vzv​。

ENC(v)=zv\text{ENC}(v) = z_v ENC(v)=zv​

我们常用Shallow Encoding。编码器就是一个查找表（Embedding Look-up）。

我们为每个节点 uuu 维护一个专属的向量 zuz_uzu​。

这个向量是通过优化过程直接学习得到的。公式表示为

ENC(v)=zv=Z⋅v\text{ENC(v)} = z_v = Z \cdot v ENC(v)=zv​=Z⋅v

其中 ZZZ 是一个矩阵，每一列是一个节点的嵌入，也是我们去优化的对象，vvv 是一个指示向量。

定义节点相似度函数 (Similarity Function)

这是不同方法（如DeepWalk, Node2Vec）的关键区别所在。例如，相连的节点是相似的，或者有共同邻居的节点是相似的。

解码器 (Decoder)

DEC将嵌入空间中的向量对映射为一个相似度分数。

最常用的解码器是点积（Dot Product）。即，节点 uuu 和 vvv 在嵌入空间中的相似度为

similarity(u,v)=zvTzu\text{similarity}(u, v) = z^T_v z_u similarity(u,v)=zvT​zu​

基于随机游走的节点嵌入 (Random Walk Approaches)

随机游走的想法不再仅仅依赖于直接的连接（一阶相似度），而是认为：如果两个节点频繁出现在同一条随机游走路径上，那么它们就是相似的。 这可以捕捉到高阶的、多跳的邻域信息。

  • zu\mathbf{z}_uzu​：节点 uuu 的嵌入向量（我们要学的）。
  • $ P(v|\mathbf{z}_u) $：基于当前嵌入，模型预测从 uuu 出发的随机游走会访问到 vvv 的概率。

从而我们的方法为：

  1. 使用某种随机游走策略 RRR，在图上跑游走，统计出真实的共现概率 PR(v∣u)P_R(v|u)PR​(v∣u)。
  2. 调整嵌入 zu\mathbf{z}_uzu​，使得嵌入空间中的点积相似度（zuTzv\mathbf{z}_u^T\mathbf{z}_vzuT​zv​ ）能拟合上述统计出的共现概率。

定义NR(u)N_R(u)NR​(u) 表示通过策略 RRR 从 uuu 出发进行随机游走所访问到的节点集。

目标函数为：

arg⁡max⁡z∑u∈Vlog⁡P(NR(u)∣zu)\underset{\mathbf{z}}{\arg \max} \sum_{u \in V} \log P(N_R(u) | \mathbf{z}_u) zargmax​u∈V∑​logP(NR​(u)∣zu​)

也就是说我们希望对于每个节点 uuu，给定它的嵌入zu\mathbf{z}_uzu​，它能预测自己随机游走邻域里出现的那些节点 $v $。

负似然函数为：

L=∑u∈V∑v∈NR(u)−log⁡(P(v∣zu))\mathcal{L} = \sum_{u \in V} \sum_{v \in N_R(u)} - \log(P(v|\mathbf{z}_u)) L=u∈V∑​v∈NR​(u)∑​−log(P(v∣zu​))

下面需要定义 P(v∣zu)P(v|\mathbf{z}_u)P(v∣zu​):

P(v∣zu)=exp⁡(zuTzv)∑n∈Vexp⁡(zuTzn)P(v|\mathbf{z}_u) = \frac{\exp(\mathbf{z}_u^T \mathbf{z}_v)}{\sum_{n \in V} \exp(\mathbf{z}_u^T \mathbf{z}_n)} P(v∣zu​)=∑n∈V​exp(zuT​zn​)exp(zuT​zv​)​

这里使用Softmax因为Softmax提供了一个全局归一化的概率分布。它强制模型不仅要把正样本vvv 的点积拉高，还要把所有其他节点nnn（负样本）的点积压下去。这保证了向量空间的区分度。

然而这样做的复杂度是 O(∣V∣2)O(|V|^2)O(∣V∣2)， 在大规模图（百万级节点）上，这是完全不可行的。

我们可以使用负采样(Negative Sampling)去优化。

“Technically, this is a different objective.”

现在需要优化的新似然函数为：

log⁡(σ(zuTzv))+∑i=1klog⁡(σ(−zuTzni)),ni∼Pv\log \left( \sigma(\mathbf{z}_u^T \mathbf{z}_v) \right) + \sum_{i=1}^{k} \log \left( \sigma(-\mathbf{z}_u^T \mathbf{z}_{n_i}) \right), \quad n_i \sim P_v log(σ(zuT​zv​))+i=1∑k​log(σ(−zuT​zni​​)),ni​∼Pv​

  • 第一项（正样本）：最大化真实共现节点对 (u,v)(u, v)(u,v) 的点积通过Sigmoid后的概率（拉近它们）。
  • 第二项（负样本）：随机抽取 kkk 个“负样本”节点 nin_ini​，最小化它们的点积（推开它们）。

下面的工作就是去优化：

总Loss：

L=∑u∈V∑v∈NR(u)−log⁡(P(v∣zu))\mathcal{L} = \sum_{u \in V} \sum_{v \in N_R(u)} -\log(P(v|\mathbf{z}_u)) L=u∈V∑​v∈NR​(u)∑​−log(P(v∣zu​))

SGD更新：随机采样一个节点 uuu ，只看它的局部损失 L(u)\mathcal{L}^{(u)}L(u) ，计算梯度，然后更新它及其邻居的嵌入向量。

最终算法：

  1. 对每个节点跑固定长度的随机游走。
  2. 收集所有节点被访问到的多重集 NR(u)N_R(u)NR​(u)。
  3. 利用负采样加速SGD，优化嵌入矩阵 Z\mathbf{Z}Z。

下面的问题在于如何设计游走策略：

  1. 无偏随机游走：从每个节点出发，完全随机地选择邻居前进。

  2. 二阶偏置随机游走（2nd Order Biased Walks）

Node2Vec引入了两个超参数 ppp 和 qqq，在BFS和DFS之间插值。

假设游走刚刚从节点 ttt 走到了当前节点 www。现在我们要决定从 www 走向它的邻居 xxx。

未归一化的转移概率公式：

αpq(t,x)={1p如果 x=t(走回头路)1如果 x 与 t 直接相连(距离=1)1q如果 x 与 t 不相连(距离=2)\alpha_{pq}(t, x) = \begin{cases} \frac{1}{p} & \text{如果 } x = t \quad (\text{走回头路}) \\ 1 & \text{如果 } x \text{ 与 } t \text{ 直接相连} \quad (\text{距离=1}) \\ \frac{1}{q} & \text{如果 } x \text{ 与 } t \text{ 不相连} \quad (\text{距离=2}) \end{cases} αpq​(t,x)=⎩⎨⎧​p1​1q1​​如果 x=t(走回头路)如果 x 与 t 直接相连(距离=1)如果 x 与 t 不相连(距离=2)​

  1. 如果 ppp 很小（<1），游走倾向于回到 ttt 。这会导致游走被困在局部区域震荡，模拟了BFS。

  2. 如果 qqq 很小（<1），游走倾向于走向离 ttt 更远的节点（距离=2）。这模拟了 DFS 的宏观结构。

随机游走的数学思考

随机游走本质上等价于矩阵分解。

如果我们定义节点相似度很简单——“两个节点由一条边连接即为相似”。
