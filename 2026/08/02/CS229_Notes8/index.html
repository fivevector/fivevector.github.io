CS229 Notes 8 : LLM 基础 (1)

CS229 Notes 8: LLM基础 (1)

这个系列是本人学习CS229的学习笔记。本文是第八篇文章，对应大语言模型系列讲座的第一部分。

一、Tokenization

Tokenization 要解决的核心问题是：输入给语言模型的最小单元是什么？ 最自然的想法要么是字符，要么是单词。

  • 字符级分词（character-level tokenization）：问题是 token 数量太多——一句话会被拆成很多很多个字符，模型需要很多步才能处理完，计算开销大。

  • 词级分词（word-level tokenization）：问题出在罕见的、很长的词上。例如 internationalization（国际化）这个词，如果把它当作一个独立的单词，它出现的频率可能非常低，模型几乎学不到关于它的信息；而且把它当作一个整体，就与 internationalize、nation 等词完全割裂开了，无法共享已有的理解。如果模型已经理解了 internationalize，那么即便没见过 internationalization，也应该能对它有相当程度的理解。词级分词恰恰浪费了这种迁移能力。

因此人们通常采用子词分词（subword tokenization）。举例来说，LMMification 这样的新造词，如果把它当作单一 token，模型必须见过这个词很多次才能理解它；但如果拆成子词，比如 LMM 是一个 token、ification 是一个 token（-ification 在英语里有"使……化"的含义），那么模型已经见过 LMM 很多次、也理解 ification 的构词含义，把两者结合起来就能"拼"出这个词的意思，学习效率高得多。

实际操作上，tokenization 意味着模型有一个预定义的词汇表（vocabulary），它是一个子词列表。很多常见词整体作为一个 token，例如 a、dog；甚至"空格 + dog"（即 dog）整体也是一个 token。

关于词汇表的规模：目前开源模型通常在 10510^5105（十万）量级、至少约 100k。较好的开源模型词汇表约有 250k 个 token，218=2621442^{18}=262144218=262144，即约 18 比特。

有了词汇表，给定一段文本，tokenizer 就把它切成一串 token，每个 token 有一个 ID。例如 A 的 ID 可能是 1、dog 的 ID 可能是 356、runs 的 ID 可能是 250。于是任何文本都被转换成一个 ID 序列，每个 ID 对应一个 token。

二、自回归语言建模与链式法则

从本讲起，我们约定已经有一个 tokenizer：任何文本都会被转成 token 序列，记为

x1,x2,…,xT,x_1, x_2, \dots, x_T, x1​,x2​,…,xT​,

其中每个 xix_ixi​ 都属于词汇表 VVV（记 ∣V∣|V|∣V∣ 为其大小，可能达到 250k）。每个 xix_ixi​ 就是词汇表里的一个索引。

要为 token 序列的概率分布建模，每个位置有 ∣V∣|V|∣V∣ 种选择，长度为 TTT 的序列共有 ∣V∣T|V|^T∣V∣T 种可能组合。

因此人们用链式法则（Chain Rule） 把联合分布分解成条件概率的乘积：

p(x1,x2,…,xT)=p(x1) p(x2∣x1) p(x3∣x1,x2)⋯p(xT∣x1,…,xT−1)=∏t=1Tp(xt∣x1,…,xt−1).p(x_1, x_2, \dots, x_T) = p(x_1)\,p(x_2\mid x_1)\,p(x_3\mid x_1,x_2)\cdots p(x_T\mid x_1,\dots,x_{T-1}) = \prod_{t=1}^{T} p(x_t\mid x_1,\dots,x_{t-1}). p(x1​,x2​,…,xT​)=p(x1​)p(x2​∣x1​)p(x3​∣x1​,x2​)⋯p(xT​∣x1​,…,xT−1​)=t=1∏T​p(xt​∣x1​,…,xt−1​).

这就是条件概率分解（Conditional Probability Decomposition）。它的好处是：每一个条件分布 p(xt∣x1,…,xt−1)p(x_t\mid x_1,\dots,x_{t-1})p(xt​∣x1​,…,xt−1​) 只需要在 ∣V∣|V|∣V∣ 个选择上做一次 softmax，是一个合法的、参数规模很小的分布；把所有这些条件分布乘起来就得到整个序列的联合分布。

每一个条件分布都由一个神经网络来参数化：网络的输入是之前的 token（条件部分），输出是下一个 token 上的分布。也就是说，建模

pθ(xt∣x1,…,xt−1),p_\theta(x_t \mid x_1, \dots, x_{t-1}), pθ​(xt​∣x1​,…,xt−1​),

其中 θ\thetaθ 是网络参数。这个网络就是 Transformer。给定序列 x1,…,xt−1x_1,\dots,x_{t-1}x1​,…,xt−1​，Transformer 输出 xtx_txt​ 上的一个概率分布。这正是自回归语言模型的核心抽象。

三、Transformer 黑盒

Transformer 的输入是离散的 token ID 序列 x1,…,xTx_1,\dots,x_Tx1​,…,xT​。第一步是把每个离散 ID 变成一个数值向量：嵌入（Embedding）。

具体做法是定义一个嵌入矩阵。设嵌入维度为 ddd，词汇表大小为 ∣V∣|V|∣V∣，则嵌入矩阵是

E∈R∣V∣×d,E \in \mathbb{R}^{|V|\times d}, E∈R∣V∣×d,

矩阵的每一行对应词汇表中的一个 token，是一个 ddd 维的行向量。这个矩阵的参数是可学习的：训练时通过调整参数找到合适的嵌入。

给定 token xtx_txt​（它是词汇表的一个索引），取出嵌入矩阵的第 xtx_txt​ 行，得到嵌入向量

et=Ext∈R1×d.e_t = E_{x_t} \in \mathbb{R}^{1\times d}. et​=Ext​​∈R1×d.

于是序列 x1,…,xTx_1,\dots,x_Tx1​,…,xT​ 变成嵌入序列 e1,…,eTe_1,\dots,e_Te1​,…,eT​，或者写成 E(x1),…,E(xT)E(x_1),\dots,E(x_T)E(x1​),…,E(xT​)。

值得注意的是，ddd 与词汇表大小 ∣V∣|V|∣V∣ 相比通常小得多——词汇表可能有 250k 个 token，而嵌入维度 ddd 是模型的一个超参数（如数千量级）。嵌入矩阵把"离散、稀疏"的 token ID 表示转换成"稠密、连续"的低维向量。

在很多情况下，人们会在序列最前面追加一个固定的句首 token（Beginning-of-Sentence Token），记作 x0x_0x0​。词汇表里通常会预留一些特殊 token（Special Tokens） 用于此类用途。引入 x0x_0x0​ 后，Transformer 处理的输入是 x0,x1,…,xTx_0,x_1,\dots,x_Tx0​,x1​,…,xT​（在需要时）。

把中间的 Transformer 暂时当作一个黑盒。它做的事是：输入嵌入序列 E(x0),E(x1),…,E(xt−1)E(x_0),E(x_1),\dots,E(x_{t-1})E(x0​),E(x1​),…,E(xt−1​)，经过大量矩阵乘法等运算，在每个位置输出一个向量，称为该位置的 logits（逻辑值），记作 ut∈R∣V∣u_t\in\mathbb{R}^{|V|}ut​∈R∣V∣。logits 是 softmax 之前的"分数"。

记 z∈R∣V∣z\in\mathbb{R}^{|V|}z∈R∣V∣ 为任意实值向量，softmax 把它变成一个概率向量，其第 iii 个分量为

[softmax⁡(z)]i=ezi∑j=1∣V∣ezj,i=1,…,∣V∣.\bigl[\operatorname{softmax}(z)\bigr]_i = \frac{e^{z_i}}{\sum_{j=1}^{|V|} e^{z_j}},\qquad i=1,\dots,|V|. [softmax(z)]i​=∑j=1∣V∣​ezj​ezi​​,i=1,…,∣V∣.

softmax 的输出满足：所有分量非负、和为 1，即落在 ∣V∣|V|∣V∣ 维概率单纯形上。logits 越大对应的概率越大，且整个变换是光滑、可微的。

第一个（无条件的）分布来自句首 token 的输出

u1=fθ(x0),u_1 = f_\theta(x_0), u1​=fθ​(x0​),

于是 x1x_1x1​ 的分布为

p(x1)=softmax⁡(fθ(x0))=softmax⁡(u1).p(x_1) = \operatorname{softmax}\bigl(f_\theta(x_0)\bigr) = \operatorname{softmax}(u_1). p(x1​)=softmax(fθ​(x0​))=softmax(u1​).

同理，x2∣x1x_2\mid x_1x2​∣x1​ 的分布来自第二个位置的输出 u2u_2u2​：

p(x2∣x1)=softmax⁡(u2),u2=fθ(x0,x1).p(x_2\mid x_1) = \operatorname{softmax}(u_2),\qquad u_2 = f_\theta(x_0,x_1). p(x2​∣x1​)=softmax(u2​),u2​=fθ​(x0​,x1​).

一般地，对 t≥1t\ge 1t≥1 有

ut=fθ(x0,x1,…,xt−1),p(xt∣x1,…,xt−1)=softmax⁡(ut).u_t = f_\theta(x_0, x_1, \dots, x_{t-1}),\qquad p(x_t\mid x_1,\dots,x_{t-1}) = \operatorname{softmax}(u_t). ut​=fθ​(x0​,x1​,…,xt−1​),p(xt​∣x1​,…,xt−1​)=softmax(ut​).

整个黑盒视图可以概括为一条流水线：

  1. 文本被 tokenizer 切成 token 序列 x0,x1,…,xT−1x_0,x_1,\dots,x_{T-1}x0​,x1​,…,xT−1​（x0x_0x0​ 为可选的句首 token）；
  2. 查嵌入矩阵得到行向量序列 E(x0),…,E(xT−1)E(x_0),\dots,E(x_{T-1})E(x0​),…,E(xT−1​)；
  3. Transformer 逐位置输出 logits u1,…,uTu_1,\dots,u_Tu1​,…,uT​；
  4. softmax⁡(ut)\operatorname{softmax}(u_t)softmax(ut​) 给出下一个 token xtx_txt​ 的条件分布 pθ(xt∣x1,…,xt−1)p_\theta(x_t\mid x_1,\dots,x_{t-1})pθ​(xt​∣x1​,…,xt−1​)。

四、自回归生成与温度采样

有了条件分布 pθ(xt∣x1,…,xt−1)p_\theta(x_t\mid x_1,\dots,x_{t-1})pθ​(xt​∣x1​,…,xt−1​)，生成文本就是不断"采样-回喂"的过程：

  1. 先从 p(x1)=softmax⁡(u1)p(x_1)=\operatorname{softmax}(u_1)p(x1​)=softmax(u1​) 采样出第一个 token；
  2. 把第一个 token 回喂给 Transformer，重新计算 softmax，采样第二个 token；
  3. 如此往复，每次把新生成的 token 追加到输入序列末尾，再继续。

这就是自回归生成（Autoregressive Generation）。每一步生成的都是"给定已生成前缀"的下一个 token。

在实际使用中，生成往往不是从空开始：用户会给模型一段提示（Prompt）——比如一个问题、一句指令。设已给定的 token 是 x1,…,xkx_1,\dots,x_kx1​,…,xk​，模型要做的是续写：从 xk+1x_{k+1}xk+1​ 开始生成：

xk+1∼softmax⁡(fθ(x1,…,xk)),xk+2∼softmax⁡(fθ(x1,…,xk+1)), …x_{k+1} \sim \operatorname{softmax}\bigl(f_\theta(x_1,\dots,x_k)\bigr),\qquad x_{k+2} \sim \operatorname{softmax}\bigl(f_\theta(x_1,\dots,x_{k+1})\bigr),\ \dots xk+1​∼softmax(fθ​(x1​,…,xk​)),xk+2​∼softmax(fθ​(x1​,…,xk+1​)), …

生成时不一定严格按原始模型分布采样，一个常见的变体是温度采样（Temperature Sampling）：把 logits 除以一个温度（Temperature） 参数 τ\tauτ：

p(xt) ∝ exp⁡ ⁣(ut(xt)τ).p(x_t)\ \propto\ \exp\!\left(\frac{u_t^{(x_t)}}{\tau}\right). p(xt​) ∝ exp(τut(xt​)​​).

除以温度不改变各 token 之间的相对顺序，但会改变分布的尺度（Scale）。

  • 温度越小，分布越"尖"，概率质量几乎全部压在最可能的 token 上，生成趋近于确定性——相当于每步直接取最大（argmax）。
  • 温度大于 1，分布更"平"，把更多概率质量推向长尾（Long Tail），生成更多样、更随机。

实际使用中，API 调用通常有 temperature 参数：设得很小，得到确定性的输出；设为 0，则每次生成完全确定（每步取最大概率 token 继续）。

另一种常见的采样方式是 top-K 采样（Top-K Sampling）：logits 向量是 ∣V∣|V|∣V∣ 维的，只保留概率最高的 K 个 token，把其余 token 的概率全部丢弃，再在剩下的 KKK 个 token 上重新归一化。这样生成时不会去采样那些罕见 token，通常更稳健。

五、训练：负对数似然

训练目标是最大似然：让模型给训练数据以尽可能高的概率。给定一个训练样本（token 序列）x1,…,xTx_1,\dots,x_Tx1​,…,xT​，其对数似然是

log⁡pθ(x1,…,xT)=log⁡∏t=1Tpθ(xt∣x1,…,xt−1)=∑t=1Tlog⁡pθ(xt∣x1,…,xt−1).\log p_\theta(x_1,\dots,x_T) = \log \prod_{t=1}^{T} p_\theta(x_t\mid x_1,\dots,x_{t-1}) = \sum_{t=1}^{T} \log p_\theta(x_t\mid x_1,\dots,x_{t-1}). logpθ​(x1​,…,xT​)=logt=1∏T​pθ​(xt​∣x1​,…,xt−1​)=t=1∑T​logpθ​(xt​∣x1​,…,xt−1​).

训练时最小化负对数似然（Negative Log-Likelihood, NLL）：

L(θ)=−log⁡pθ(x1,…,xT)=−∑t=1Tlog⁡pθ(xt∣x1,…,xt−1)=−∑t=1Tlog⁡[softmax⁡(ut)]xt,\mathcal{L}(\theta) = -\log p_\theta(x_1,\dots,x_T) = -\sum_{t=1}^{T} \log p_\theta(x_t\mid x_1,\dots,x_{t-1}) = -\sum_{t=1}^{T} \log \bigl[\operatorname{softmax}(u_t)\bigr]_{x_t}, L(θ)=−logpθ​(x1​,…,xT​)=−t=1∑T​logpθ​(xt​∣x1​,…,xt−1​)=−t=1∑T​log[softmax(ut​)]xt​​,

其中 ut=fθ(x0,…,xt−1)u_t=f_\theta(x_0,\dots,x_{t-1})ut​=fθ​(x0​,…,xt−1​)。要点在于：softmax 会为每一个可能的 token 给出概率，而我们只关心数据里真实出现的那个 token xtx_txt​ 的概率，所以取的是 softmax 向量的第 xtx_txt​ 个分量——取对数后对 ttt 求和，再取负，就是损失。

损失是对 t=1t=1t=1 到 TTT 的所有位置求和，每个位置的真实 token 都参与贡献，而不是只看最后一步。

得到损失后，用标准的优化器（如 SGD，或 Adam）对 θ\thetaθ 求梯度并更新参数。由于整个 Transformer 是大量矩阵乘法等基本运算的复合，自动微分（Automatic Differentiation） 可以高效地求出梯度。

六、Transformer 高层结构

Transformer 由多层（Layers） 堆叠而成。以嵌入序列 E(x1),…,E(xT)E(x_1),\dots,E(x_T)E(x1​),…,E(xT​)（可能带句首 token）作为输入，其宏观结构是：注意力层（Attention Layer）与 MLP 交替。

具体流程如下：

  1. 先应用一个注意力层（Attention）。注意力层的"类型签名"是：输入一个向量序列，输出一个向量序列——在每个位置各输出一个向量。
  2. 每个输出向量再经过一个 MLP（Multi-Layer Perceptron，多层感知机）。
  3. 之后再接一个注意力层，再经过 MLP……如此交替若干轮。
  4. 最后再经过一个 MLP，输出序列 u1,…,uTu_1,\dots,u_Tu1​,…,uT​——也就是逐位置的 logits。

所以整个 Transformer 就是"注意力 →\to→ MLP →\to→ 注意力 →\to→ MLP →⋯\to\cdots→⋯"的交替堆叠。

关于 MLP 有两个要点：

  • 参数共享：每一层里，不同位置用的是同一个 MLP（同一套参数）；
  • 逐位置独立：MLP 对每个位置的向量独立地处理，不同位置之间没有任何交互。

因此，唯一让不同位置（不同时间步）的信息发生交互的地方就是注意力层。注意力层"看到"所有位置的向量，经过内部运算后输出新的一批向量；MLP 则高度并行、彼此独立地对每个向量做变换。

七、单头注意力

注意力层的类型签名（Type Signature）：输入一个向量序列，输出一个向量序列。设输入的向量序列为 h1in,…,hTinh_1^{\text{in}},\dots,h_T^{\text{in}}h1in​,…,hTin​，注意力层输出 h1out,…,hTouth_1^{\text{out}},\dots,h_T^{\text{out}}h1out​,…,hTout​。每个向量都是行向量（乘法在右侧）。设输入向量 htin∈R1×dh_t^{\text{in}}\in\mathbb{R}^{1\times d}htin​∈R1×d。

注意力的第一个操作是把每个输入向量投影成三类向量：查询（Query）、键（Key）、值（Value）。

对每个位置 ttt 定义

qt=htin WQ,kt=htin WK,vt=htin WV,q_t = h_t^{\text{in}}\, W_Q,\qquad k_t = h_t^{\text{in}}\, W_K,\qquad v_t = h_t^{\text{in}}\, W_V, qt​=htin​WQ​,kt​=htin​WK​,vt​=htin​WV​,

其中 WQ,WK,WVW_Q,W_K,W_VWQ​,WK​,WV​ 是可学习的投影矩阵，维数为

WQ,WK,WV∈Rd×dh,W_Q, W_K, W_V \in \mathbb{R}^{d \times d_h}, WQ​,WK​,WV​∈Rd×dh​,

dhd_hdh​ 是自行选择的维度（注意力内部空间的维数）。于是 qt,kt,vt∈R1×dhq_t,k_t,v_t\in\mathbb{R}^{1\times d_h}qt​,kt​,vt​∈R1×dh​。

取位置 ttt 的查询 qtq_tqt​，让它与所有位置的键做内积：

qtk1T, qtk2T, …, qtkTT.q_t k_1^{\mathsf T},\ q_t k_2^{\mathsf T},\ \dots,\ q_t k_T^{\mathsf T}. qt​k1T​, qt​k2T​, …, qt​kTT​.

（qtq_tqt​ 是行向量，kiTk_i^{\mathsf T}kiT​ 是列向量，所以 qtkiTq_t k_i^{\mathsf T}qt​kiT​ 是内积，得到一个标量。）实践中通常还会除以一个缩放因子（Scaling Factor） ccc（记作 qtkiT/cq_t k_i^{\mathsf T}/cqt​kiT​/c），用于让数值更规整、训练更稳定。

得到 TTT 个实数，把它们排成一个 TTT 维向量，再对它做 softmax：

pt=(pt1,pt2,…,ptT)=softmax⁡ ⁣(qtk1Tc, qtk2Tc, …, qtkTTc).p_t = \bigl(p_{t1}, p_{t2}, \dots, p_{tT}\bigr) = \operatorname{softmax}\!\left(\frac{q_t k_1^{\mathsf T}}{c},\, \frac{q_t k_2^{\mathsf T}}{c},\,\dots,\, \frac{q_t k_T^{\mathsf T}}{c}\right). pt​=(pt1​,pt2​,…,ptT​)=softmax(cqt​k1T​​,cqt​k2T​​,…,cqt​kTT​​).

softmax 之后，ptp_tpt​ 是一个概率向量：每个分量 pti≥0p_{ti}\ge 0pti​≥0，且 ∑i=1Tpti=1\sum_{i=1}^{T}p_{ti}=1∑i=1T​pti​=1。如果 qtq_tqt​ 与 kik_iki​ 的内积很大，说明两者匹配程度高，softmax 后对应的 ptip_{ti}pti​ 也大，即位置 ttt 应当多注意位置 iii。

最后，用概率向量 ptp_tpt​ 对值向量做加权（凸）组合，得到位置 ttt 的输出：

htout=pt1 v1+pt2 v2+⋯+ptT vT=∑i=1Tpti vi.h_t^{\text{out}} = p_{t1}\, v_1 + p_{t2}\, v_2 + \cdots + p_{tT}\, v_T = \sum_{i=1}^{T} p_{ti}\, v_i. htout​=pt1​v1​+pt2​v2​+⋯+ptT​vT​=i=1∑T​pti​vi​.

整个机制概括为三步：

  1. 投影：输入 →\to→ QKV；
  2. 打分：查询与所有键做内积、除以缩放因子、softmax →\to→ 注意力权重；
  3. 聚合：以权重对值加权求和 →\to→ 输出。

所有投影矩阵 WQ,WK,WVW_Q,W_K,W_VWQ​,WK​,WV​ 都是可学习的："注意谁"这件事本身也是学出来的。

把所有查询、键、值分别堆叠成矩阵：

Q=[q1q2⋮qT]∈RT×dh,K=[k1k2⋮kT]∈RT×dh,V=[v1v2⋮vT]∈RT×dh.Q = \begin{bmatrix} q_1 \\ q_2 \\ \vdots \\ q_T \end{bmatrix}\in\mathbb{R}^{T\times d_h},\qquad K = \begin{bmatrix} k_1 \\ k_2 \\ \vdots \\ k_T \end{bmatrix}\in\mathbb{R}^{T\times d_h},\qquad V = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_T \end{bmatrix}\in\mathbb{R}^{T\times d_h}. Q=​q1​q2​⋮qT​​​∈RT×dh​,K=​k1​k2​⋮kT​​​∈RT×dh​,V=​v1​v2​⋮vT​​​∈RT×dh​.

整个单头注意力可以写成简洁的矩阵表达式：

Hout=softmax⁡ ⁣(QKTc)V.H_{\text{out}} = \operatorname{softmax}\!\left(\frac{Q K^{\mathsf T}}{c}\right) V. Hout​=softmax(cQKT​)V.

其中 softmax⁡\operatorname{softmax}softmax 是按行做的（每一行是一个概率向量）；再右乘 VVV，就是"以注意力权重对值做线性组合"。

观察上述架构会发现一个"作弊"之处：位置 ttt 的输出依赖所有位置的输入——包括未来的位置。但自回归模型在生成 ttt 时刻的 token 时，不可能看到未来。因此必须引入遮蔽（Masking），强制 htouth_t^{\text{out}}htout​ 只依赖 ttt 及之前的位置。

具体做法：在 QKTQK^{\mathsf T}QKT 矩阵的上三角部分（所有 j>ij>ij>i 的项 qikjTq_i k_j^{\mathsf T}qi​kjT​）加上 −∞-\infty−∞：

(QKT)ij←(QKT)ij−∞,j>i.(QK^{\mathsf T})_{ij} \leftarrow (QK^{\mathsf T})_{ij} - \infty,\qquad j > i. (QKT)ij​←(QKT)ij​−∞,j>i.

对这样处理过的矩阵做逐行 softmax 时，e−∞=0e^{-\infty}=0e−∞=0，所以所有未来位置对应的注意力权重都变为 0，而剩余（过去与当前）位置的权重自动重新归一化为和为 1。输出退化为

htout=∑i=1tpti vi,h_t^{\text{out}} = \sum_{i=1}^{t} p_{ti}\, v_i, htout​=i=1∑t​pti​vi​,

即只用到 v1,…,vtv_1,\dots,v_tv1​,…,vt​。这正是自回归所需的因果结构。

八、多头注意力与归一化残差

多头注意力（Multi-Head Attention） 的做法是：并行运行多个单头注意力，每个头有各自不同的投影矩阵。

假设有 NhN_hNh​ 个 head。第 jjj 个 head 有自己的权重矩阵 WQ(j),WK(j),WV(j)W_Q^{(j)},W_K^{(j)},W_V^{(j)}WQ(j)​,WK(j)​,WV(j)​，各自对同一个输入序列做单头注意力，得到各自的输出序列。这些头是并行的——它们都直接吃同一份输入，彼此之间没有先后依赖。

最终把 NhN_hNh​ 个头的结果合并起来：把同一位置的 NhN_hNh​ 个头输出拼接（Concatenate） 成一个长向量，再乘一个投影矩阵（Projection Matrix） WOW_OWO​：

htout=[ht(1) ∣ ht(2) ∣ ⋯ ∣ ht(Nh)] WO.h_t^{\text{out}} = \Bigl[h_t^{(1)}\ \bigl|\ h_t^{(2)}\ \bigl|\ \cdots\ \bigl|\ h_t^{(N_h)}\Bigr]\, W_O. htout​=[ht(1)​ ​ ht(2)​ ​ ⋯ ​ ht(Nh​)​]WO​.

为什么多头有帮助？每个头可能在做不同类型的注意力任务。比如某个头可能在找"前面段落里与当前相关的实体是哪个"，另一个头可能在分析"过去内容的情感如何"。每个头注意不同类型的信息，最后把所有头的产出聚合，给模型更强的表达能力。

头数大约最多在 100 的量级，取决于模型规模。

真实的层结构比"注意力 + MLP"更复杂，大致是：

  1. 输入 →\to→ 归一化 →\to→ 注意力 →\to→ 残差加回；
  2. 再归一化 →\to→ MLP →\to→ 残差加回；
  3. 进入下一层，如此循环。
  • 归一化层（Normalization Layer）：常用的是 RMSNorm；
  • 残差连接（Residual Connection）：把注意力/MLP 的输出加回到其输入上，与 ResNet 残差结构类似。

关于残差与归一化的顺序，存在不同的安排方式（post-norm / pre-norm）。

九、计算效率与内存占用

关键在于对序列长度 TTT 的依赖。注意力矩阵 QKTQK^{\mathsf T}QKT 是 T×TT\times TT×T 的，每个元素是一个 dhd_hdh​ 维内积，总计算量约为

O(T2⋅dh),O(T^2 \cdot d_h), O(T2⋅dh​),

其中对 dhd_hdh​ 的依赖相对次要，对 T2T^2T2 的依赖才是关键。TTT 若达到百万量级，T2T^2T2 就是 101210^{12}1012 次运算量——不可行。这正是长上下文（Long Context） 问题的根源。

实践中往往更接近线性，因为有各种降低对 TTT 依赖的 Transformer 变体。但这类修改往往以表达力（Expressiveness） 为代价。

内存方面：注意力矩阵 QKTQK^{\mathsf T}QKT 本身就需要 O(T2)O(T^2)O(T2) 的内存。但可以通过分块（Block-wise）计算来降低：先算一部分注意力矩阵、与对应的 VVV 块相乘、累加部分结果，然后丢掉这部分矩阵，再算下一块。这样就不需要保存完整的 T×TT\times TT×T 矩阵。这个想法就是著名的 Flash Attention（闪光注意力），用于降低内存占用。

效率与能力之间需要取舍。降低 TTT 依赖的架构变体往往以表达力为代价。
