通过这些通用算法，一个典型的深度学习模型按以下步骤学习：

神经网络

神经网络 (Neural Networks) 是指一类广泛的非线性模型/参数化 hˉθ(x)\bar{h}_\theta(x)hˉθ​(x)，它们涉及矩阵乘法和其它逐点非线性操作的组合。为了统一处理回归问题和分类问题，这里我们将 hˉθ(x)\bar{h}_\theta(x)hˉθ​(x) 视为神经网络的输出。

  • 对于回归问题，最终预测值为 hθ(x)=hˉθ(x)h_\theta(x) = \bar{h}_\theta(x)hθ​(x)=hˉθ​(x)。
  • 对于分类问题，hˉθ(x)\bar{h}_\theta(x)hˉθ​(x) 是 logits，预测概率为：
    • 二分类：hθ(x)=11+exp⁡(−hˉθ(x))h_\theta(x) = \frac{1}{1 + \exp(-\bar{h}_\theta(x))}hθ​(x)=1+exp(−hˉθ​(x))1​（见公式 7.3）。
    • 多分类：hθ(x)=softmax(hˉθ(x))h_\theta(x) = \text{softmax}(\bar{h}_\theta(x))hθ​(x)=softmax(hˉθ​(x))（见公式 7.5）。

单个神经元的神经网络

我们定义一个参数化函数 hˉθ(x)\bar{h}_\theta(x)hˉθ​(x)，输入为 xxx，参数为 θ\thetaθ，输出 yyy。形式上，hˉθ:x→y\bar{h}_\theta: x \to yhˉθ​:x→y。也许最简单的参数化形式是：

这里 hˉθ(x)\bar{h}_\theta(x)hˉθ​(x) 返回一个值：(wx+b)(wx + b)(wx+b) 或 0，取较大者。在神经网络的语境中，函数 max⁡{t,0}\max\{t, 0\}max{t,0} 被称为 ReLU，即修正线性单元 (Rectified Linear Unit)，通常记为 ReLU(t)≜max⁡{t,0}\text{ReLU}(t) \triangleq \max\{t, 0\}ReLU(t)≜max{t,0}。

向量化（Vectorization）

在引入更多层和更复杂结构的神经网络之前，我们将使用更多的矩阵和向量符号来简化神经网络的表达式。向量化的另一个重要动机是实现中的速度考虑。为了高效地实现神经网络，使用 for 循环时必须小心。最自然的方式是用 for 循环实现公式 (7.15) 中的计算。但在实践中，输入和隐藏单元的维度很高，如果使用 for 循环，代码会运行得非常慢。利用 GPU 的并行性对于深度学习的进步至关重要。

向量化不是使用 for 循环，而是利用矩阵代数和高性能数值线性代数包（如 BLAS）来使神经网络计算快速运行。在深度学习时代之前，对于较小的数据集，for 循环可能就足够了，但现代深度网络和最先进的数据集如果不使用向量化将难以运行。

借助这些简洁的符号，我们可以堆叠更多层以获得更深的全连接神经网络。设 rrr 为层数（权重矩阵的数量）。设 W[1],…,W[r],b[1],…,b[r]W^{[1]}, \ldots, W^{[r]}, b^{[1]}, \ldots, b^{[r]}W[1],…,W[r],b[1],…,b[r] 为所有层的权重矩阵和偏置。则多层神经网络可写为：

ReLU 激活函数可以替换为许多其他从 R\mathbb{R}R 映射到 R\mathbb{R}R 的非线性函数 σ(⋅)\sigma(\cdot)σ(⋅)，例如：

Sigmoid 和 Tanh 如今使用得越来越少，部分原因是它们上下界均有界，并且当 zzz 趋向正负无穷时梯度消失（而其他激活函数在输入趋向正无穷时仍保持梯度）。Softplus 在实践中也不常用，它可以看作是 ReLU 的光滑近似，使其具有二阶导数。GELU 和 Leaky ReLU 都是 ReLU 的变体，但它们在输入为负时仍有非零梯度。GELU（或其轻微变体）被用于 BERT 和 GPT 等 NLP 模型中。

与核方法的联系

特征映射的主要动机是通过 θ⊤ϕ(x)\theta^\top \phi(x)θ⊤ϕ(x) 来表示对输入 xxx 非线性的函数，其中 θ\thetaθ 是参数，ϕ(x)\phi(x)ϕ(x) 是手工设计的、对原始输入 xxx 非线性的特征映射。学习算法的性能在很大程度上取决于特征映射 ϕ(x)\phi(x)ϕ(x) 的选择。人们通常使用领域知识来设计 ϕ(x)\phi(x)ϕ(x)，以便使问题更容易。

神经网络可以看作是一种自动学习适当特征映射的方式：前 r−1r-1r−1 层可以看作是一个特征映射 ϕθ(x)=a[r−1]\phi_\theta(x) = a^{[r-1]}ϕθ​(x)=a[r−1]（它本身由 xxx 参数化），最后一层则是该特征上的线性模型。因此，我们使用数据来学习一个良好的特征映射，而不是手动设计它。这是深度学习的核心理念之一。

现代神经网络中的模块

深度学习的实践不仅依赖于全连接层（MLP），还依赖于大量其他可组合的模块。在本节中，我们将介绍其中的一些构建模块，并讨论可能的组合方式。

首先，每个矩阵乘法都可以看作一个构建模块。考虑一个带有参数 (W,b)(W, b)(W,b) 的矩阵乘法模块，其中 WWW 是权重矩阵，bbb 是偏置向量，作用于输入 zzz：

Layer Normalization

Layer Normalization，本文中记为 LN，是一个将向量 z∈Rmz \in \mathbb{R}^mz∈Rm 映射到更归一化的向量 LN(z)∈Rm\text{LN}(z) \in \mathbb{R}^mLN(z)∈Rm 的模块。它通常用在非线性激活之后。
