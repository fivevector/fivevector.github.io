CS229 Notes 1 ：监督学习

监督学习基础

监督学习的基础是一个假设（hypothesis），即从输入空间 X\mathcal{X}X 到输出空间 Y\mathcal{Y}Y 的一个函数 h:X↦Yh: \mathcal{X} \mapsto \mathcal{Y}h:X↦Y。监督学习的“监督”来自训练集（training set）——一组已知输入输出配对的数据：

{(x(1),y(1)),(x(2),y(2)),…,(x(n),y(n))},\{(x^{(1)}, y^{(1)}), (x^{(2)}, y^{(2)}), \dots, (x^{(n)}, y^{(n)})\}, {(x(1),y(1)),(x(2),y(2)),…,(x(n),y(n))},

其中 x(i)x^{(i)}x(i) 是第 iii 个样本的输入特征，y(i)y^{(i)}y(i) 是对应的标签。用上标表示样本序号，下标表示特征分量。

学习的目标是找到一个在训练集上表现良好、且能泛化（generalize） 到未见数据的假设。若 yyy 是连续的，称为回归问题（regression）；若 yyy 取离散值，称为分类问题（classification）。

二、线性回归与最小二乘

2.1 假设与参数

最简单的假设是线性（仿射）函数。引入约定 x0=1x_0 = 1x0​=1（截距项），可将偏置项吸收进参数向量：

hθ(x)=∑j=0dθjxj=θTx,h_\theta(x) = \sum_{j=0}^{d} \theta_j x_j = \theta^T x, hθ​(x)=j=0∑d​θj​xj​=θTx,

其中 θ∈Rd+1\theta \in \mathbb{R}^{d+1}θ∈Rd+1 是参数向量，x∈Rd+1x \in \mathbb{R}^{d+1}x∈Rd+1 是增广特征向量（x0=1x_0=1x0​=1）。此即“线性”名称的来源——虽本质是仿射，但通过 x0=1x_0=1x0​=1 的约定将其统一为线性形式。

2.2 最小二乘代价函数

定义代价函数（cost function） 为误差平方和的一半：

J(θ)=12∑i=1n(hθ(x(i))−y(i))2.J(\theta) = \frac{1}{2} \sum_{i=1}^{n} \left( h_\theta(x^{(i)}) - y^{(i)} \right)^2. J(θ)=21​i=1∑n​(hθ​(x(i))−y(i))2.

系数 1/21/21/2 仅为后续求导方便（会与平方项求导产生的 2 抵消），不影响 arg⁡min⁡\arg\minargmin。学习即求解：

θ∗=arg⁡min⁡θJ(θ).\theta^* = \arg\min_{\theta} J(\theta). θ∗=argθmin​J(θ).

2.3 梯度下降

对 J(θ)J(\theta)J(θ) 求偏导：

∂∂θjJ(θ)=∑i=1n(hθ(x(i))−y(i))xj(i).\frac{\partial}{\partial \theta_j} J(\theta) = \sum_{i=1}^{n} \left( h_\theta(x^{(i)}) - y^{(i)} \right) x_j^{(i)}. ∂θj​∂​J(θ)=i=1∑n​(hθ​(x(i))−y(i))xj(i)​.

批量梯度下降（Batch Gradient Descent） 每步使用全部 nnn 个样本：

θj:=θj−α∑i=1n(hθ(x(i))−y(i))xj(i),\theta_j := \theta_j - \alpha \sum_{i=1}^{n} \left( h_\theta(x^{(i)}) - y^{(i)} \right) x_j^{(i)}, θj​:=θj​−αi=1∑n​(hθ​(x(i))−y(i))xj(i)​,

写成向量形式：

θ:=θ−α∑i=1n(hθ(x(i))−y(i))x(i).\theta := \theta - \alpha \sum_{i=1}^{n} \left( h_\theta(x^{(i)}) - y^{(i)} \right) x^{(i)}. θ:=θ−αi=1∑n​(hθ​(x(i))−y(i))x(i).

当 nnn 极大时，批量梯度下降每步代价高昂。随机梯度下降（Stochastic Gradient Descent, SGD） 每次仅用一个样本更新：

θ:=θ−α(hθ(x(i))−y(i))x(i),\theta := \theta - \alpha \left( h_\theta(x^{(i)}) - y^{(i)} \right) x^{(i)}, θ:=θ−α(hθ​(x(i))−y(i))x(i),

循环遍历训练集（通常随机打乱顺序）。Mini-batch SGD 则每次使用 BBB 个样本（BBB 为批大小）：

θ:=θ−αB∑k=1B(hθ(x(ik))−y(ik))x(ik).\theta := \theta - \frac{\alpha}{B} \sum_{k=1}^{B} \left( h_\theta(x^{(i_k)}) - y^{(i_k)} \right) x^{(i_k)}. θ:=θ−Bα​k=1∑B​(hθ​(x(ik​))−y(ik​))x(ik​).

SGD 虽噪声大、可能在最优附近弹跳，但收敛快、能处理海量数据，是深度学习的主力优化器。批大小的选择常受限于 GPU 内存：越大则梯度估计越准，但计算开销也越大；实践中常按硬件容量设定。

2.4 正规方程

将数据堆成设计矩阵（design matrix） X∈Rn×(d+1)X \in \mathbb{R}^{n \times (d+1)}X∈Rn×(d+1)（每行一个样本）和标签向量 y∈Rny \in \mathbb{R}^ny∈Rn。则代价函数可写为：

J(θ)=12∥Xθ−y∥2=12(Xθ−y)T(Xθ−y).J(\theta) = \frac{1}{2} \| X\theta - y \|^2 = \frac{1}{2} (X\theta - y)^T (X\theta - y). J(θ)=21​∥Xθ−y∥2=21​(Xθ−y)T(Xθ−y).

展开并求梯度（利用 ∇θ(bTθ)=b\nabla_\theta (b^T \theta)=b∇θ​(bTθ)=b 和 ∇θ(θTAθ)=2Aθ\nabla_\theta (\theta^T A \theta)=2A\theta∇θ​(θTAθ)=2Aθ 对对称 AAA）：

∇θJ(θ)=XTXθ−XTy.\nabla_\theta J(\theta) = X^T X \theta - X^T y. ∇θ​J(θ)=XTXθ−XTy.

令梯度为零，得正规方程（Normal Equations）：

XTXθ=XTy⟹θ=(XTX)−1XTy.X^T X \theta = X^T y \quad \Longrightarrow \quad \theta = (X^T X)^{-1} X^T y. XTXθ=XTy⟹θ=(XTX)−1XTy.

此解要求 XTXX^T XXTX 可逆（即特征线性无关、n≥d+1n \ge d+1n≥d+1）。若不可逆，解为全体满足方程的参数，存在零空间自由度。

2.5 概率解释

假设数据由线性模型加噪声生成：

y(i)=θTx(i)+ϵ(i),y^{(i)} = \theta^T x^{(i)} + \epsilon^{(i)}, y(i)=θTx(i)+ϵ(i),

其中 ϵ(i)∼N(0,σ2)\epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2)ϵ(i)∼N(0,σ2) 为 IID 噪声。则：

y(i)∣x(i);θ∼N(θTx(i),σ2).y^{(i)} \mid x^{(i)}; \theta \sim \mathcal{N}(\theta^T x^{(i)}, \sigma^2). y(i)∣x(i);θ∼N(θTx(i),σ2).

其密度为：

p(y(i)∣x(i);θ)=12π σexp⁡(−(y(i)−θTx(i))22σ2).p(y^{(i)} \mid x^{(i)}; \theta) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left( -\frac{(y^{(i)} - \theta^T x^{(i)})^2}{2\sigma^2} \right). p(y(i)∣x(i);θ)=2π​σ1​exp(−2σ2(y(i)−θTx(i))2​).

似然函数（likelihood） 为：

L(θ)=∏i=1np(y(i)∣x(i);θ).L(\theta) = \prod_{i=1}^{n} p(y^{(i)} \mid x^{(i)}; \theta). L(θ)=i=1∏n​p(y(i)∣x(i);θ).

取对数似然（log-likelihood）：

ℓ(θ)=log⁡L(θ)=nlog⁡12π σ−12σ2∑i=1n(y(i)−θTx(i))2.\ell(\theta) = \log L(\theta) = n\log\frac{1}{\sqrt{2\pi}\,\sigma} - \frac{1}{2\sigma^2} \sum_{i=1}^{n} (y^{(i)} - \theta^T x^{(i)})^2. ℓ(θ)=logL(θ)=nlog2π​σ1​−2σ21​i=1∑n​(y(i)−θTx(i))2.

第一项与 θ\thetaθ 无关，因此最大化 ℓ(θ)\ell(\theta)ℓ(θ) 等价于最小化 12∑i(y(i)−θTx(i))2\frac{1}{2}\sum_i (y^{(i)} - \theta^T x^{(i)})^221​∑i​(y(i)−θTx(i))2，即最小二乘。由此，最小二乘是高斯噪声假设下的最大似然估计。

三、分类与逻辑回归

3.1 为什么线性回归不适用于分类

分类问题中 y∈{0,1}y \in \{0,1\}y∈{0,1}。若直接用线性回归，hθ(x)h_\theta(x)hθ​(x) 可能超出 [0,1][0,1][0,1] 区间；且平方损失对远离决策边界的点过于敏感，会拉偏分类面。因此需换用适合离散输出的模型。

3.2 逻辑函数与假设

定义logistic function / sigmoid：

g(z)=11+e−z.g(z) = \frac{1}{1 + e^{-z}}. g(z)=1+e−z1​.

其值域为 (0,1)(0,1)(0,1)，且满足 g′(z)=g(z)(1−g(z))g'(z) = g(z)(1-g(z))g′(z)=g(z)(1−g(z))。逻辑回归的假设为：

hθ(x)=g(θTx)=11+e−θTx.h_\theta(x) = g(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}}. hθ​(x)=g(θTx)=1+e−θTx1​.

将 hθ(x)h_\theta(x)hθ​(x) 解释为 p(y=1∣x;θ)p(y=1 \mid x; \theta)p(y=1∣x;θ)，则：

p(y=1∣x;θ)=hθ(x),p(y=0∣x;θ)=1−hθ(x),p(y=1 \mid x; \theta) = h_\theta(x),\qquad p(y=0 \mid x; \theta) = 1 - h_\theta(x), p(y=1∣x;θ)=hθ​(x),p(y=0∣x;θ)=1−hθ​(x),

可紧凑写为：

p(y∣x;θ)=hθ(x)y(1−hθ(x))1−y.p(y \mid x; \theta) = h_\theta(x)^y (1 - h_\theta(x))^{1-y}. p(y∣x;θ)=hθ​(x)y(1−hθ​(x))1−y.

3.3 最大似然与交叉熵

似然函数为：

L(θ)=∏i=1nhθ(x(i))y(i)(1−hθ(x(i)))1−y(i).L(\theta) = \prod_{i=1}^{n} h_\theta(x^{(i)})^{y^{(i)}} (1 - h_\theta(x^{(i)}))^{1-y^{(i)}}. L(θ)=i=1∏n​hθ​(x(i))y(i)(1−hθ​(x(i)))1−y(i).

对数似然为：

ℓ(θ)=∑i=1n[y(i)log⁡hθ(x(i))+(1−y(i))log⁡(1−hθ(x(i)))].\ell(\theta) = \sum_{i=1}^{n} \left[ y^{(i)} \log h_\theta(x^{(i)}) + (1 - y^{(i)}) \log (1 - h_\theta(x^{(i)})) \right]. ℓ(θ)=i=1∑n​[y(i)loghθ​(x(i))+(1−y(i))log(1−hθ​(x(i)))].

最大化 ℓ(θ)\ell(\theta)ℓ(θ) 等价于最小化交叉熵损失（cross-entropy loss）。

对单个样本求梯度（利用 g′=g(1−g)g' = g(1-g)g′=g(1−g)）：

∂∂θjℓ(θ)=(y−hθ(x))xj.\frac{\partial}{\partial \theta_j} \ell(\theta) = \left( y - h_\theta(x) \right) x_j. ∂θj​∂​ℓ(θ)=(y−hθ​(x))xj​.

于是梯度上升更新为：

θj:=θj+α(y(i)−hθ(x(i)))xj(i).\theta_j := \theta_j + \alpha \left( y^{(i)} - h_\theta(x^{(i)}) \right) x_j^{(i)}. θj​:=θj​+α(y(i)−hθ​(x(i)))xj(i)​.

此形式与线性回归的 LMS 更新完全相同，但 hθh_\thetahθ​ 现在是非线性的 sigmoid 函数。

3.4 牛顿法

逻辑回归的对数似然是凹函数，可用二阶优化加速。牛顿法（Newton’s method） 在向量情形下的更新为：

θ:=θ−H−1∇θℓ(θ),\theta := \theta - H^{-1} \nabla_\theta \ell(\theta), θ:=θ−H−1∇θ​ℓ(θ),

其中 HHH 是 Hessian 矩阵（二阶偏导）。牛顿法每步需计算和求逆 Hessian，成本 O(d3)O(d^3)O(d3)，在 ddd 不大时收敛极快；但对海量特征不适用，SGD 仍是主力。

四、指数族分布

4.1 定义

称一个分布属于指数族（Exponential Family），若其密度可写为：

p(y;η)=b(y)exp⁡ ⁣(ηTT(y)−a(η)).p(y; \eta) = b(y) \exp\!\left( \eta^T T(y) - a(\eta) \right). p(y;η)=b(y)exp(ηTT(y)−a(η)).

其中：

  • η\etaη 为自然参数（natural parameter）；
  • T(y)T(y)T(y) 为充分统计量（sufficient statistic），通常取 T(y)=yT(y)=yT(y)=y；
  • a(η)a(\eta)a(η) 为对数配分函数（log partition function），起归一化作用；
  • b(y)b(y)b(y) 为基测度（base measure）。

4.2 伯努利分布

伯努利分布 y∈{0,1}y \in \{0,1\}y∈{0,1}，p(y;ϕ)=ϕy(1−ϕ)1−yp(y;\phi)=\phi^y(1-\phi)^{1-y}p(y;ϕ)=ϕy(1−ϕ)1−y。改写：

p(y;ϕ)=exp⁡ ⁣(ylog⁡ϕ1−ϕ+log⁡(1−ϕ)).p(y;\phi) = \exp\!\left( y \log\frac{\phi}{1-\phi} + \log(1-\phi) \right). p(y;ϕ)=exp(ylog1−ϕϕ​+log(1−ϕ)).

于是：

η=log⁡ϕ1−ϕ,T(y)=y,b(y)=1,a(η)=log⁡(1+eη).\eta = \log\frac{\phi}{1-\phi},\qquad T(y)=y,\qquad b(y)=1,\qquad a(\eta)=\log(1+e^\eta). η=log1−ϕϕ​,T(y)=y,b(y)=1,a(η)=log(1+eη).

解出 ϕ=1/(1+e−η)\phi = 1/(1+e^{-\eta})ϕ=1/(1+e−η)，即 sigmoid 函数。

4.3 高斯分布

固定方差 σ2=1\sigma^2=1σ2=1 的高斯分布：

p(y;μ)=12πexp⁡ ⁣(−(y−μ)22)=12πe−y2/2exp⁡ ⁣(μy−μ22).p(y;\mu) = \frac{1}{\sqrt{2\pi}} \exp\!\left( -\frac{(y-\mu)^2}{2} \right) = \frac{1}{\sqrt{2\pi}} e^{-y^2/2} \exp\!\left( \mu y - \frac{\mu^2}{2} \right). p(y;μ)=2π​1​exp(−2(y−μ)2​)=2π​1​e−y2/2exp(μy−2μ2​).

于是 η=μ\eta = \muη=μ，T(y)=yT(y)=yT(y)=y，b(y)=12πe−y2/2b(y)=\frac{1}{\sqrt{2\pi}}e^{-y^2/2}b(y)=2π​1​e−y2/2，a(η)=η2/2a(\eta)=\eta^2/2a(η)=η2/2。

4.4 对数配分函数的性质

对指数族，有两条普适性质：

E[T(y)]=∂a(η)∂η,Var[T(y)]=∂2a(η)∂η2.\mathbb{E}[T(y)] = \frac{\partial a(\eta)}{\partial \eta},\qquad \mathrm{Var}[T(y)] = \frac{\partial^2 a(\eta)}{\partial \eta^2}. E[T(y)]=∂η∂a(η)​,Var[T(y)]=∂η2∂2a(η)​.

即 aaa 的一阶导给出期望，二阶导给出方差。证明基于归一化条件对 η\etaη 求导。

由于 Var[T(y)]≥0\mathrm{Var}[T(y)] \ge 0Var[T(y)]≥0，a(η)a(\eta)a(η) 是凸函数，因此对数似然是凹的，优化问题便于求解。

五、广义线性模型（GLM）

5.1 三个假设

给定 xxx 和 θ\thetaθ，构造 GLM 需三条假设：

  1. 条件分布 y∣x;θ∼ExponentialFamily(η)y \mid x; \theta \sim \text{ExponentialFamily}(\eta)y∣x;θ∼ExponentialFamily(η)；
  2. 预测目标为条件期望：hθ(x)=E[y∣x;θ]h_\theta(x) = \mathbb{E}[y \mid x; \theta]hθ​(x)=E[y∣x;θ]（即 T(y)=yT(y)=yT(y)=y）；
  3. 自然参数与输入线性相关：η=θTx\eta = \theta^T xη=θTx。

5.2 线性回归作为 GLM

若 y∣x;θ∼N(μ,σ2)y \mid x; \theta \sim \mathcal{N}(\mu, \sigma^2)y∣x;θ∼N(μ,σ2)，则 η=μ\eta = \muη=μ，于是：

hθ(x)=E[y∣x;θ]=μ=η=θTx.h_\theta(x) = \mathbb{E}[y \mid x; \theta] = \mu = \eta = \theta^T x. hθ​(x)=E[y∣x;θ]=μ=η=θTx.

这正是线性回归的假设。故最小二乘是 GLM 在高斯分布下的特例。

5.3 逻辑回归作为 GLM

若 y∣x;θ∼Bernoulli(ϕ)y \mid x; \theta \sim \text{Bernoulli}(\phi)y∣x;θ∼Bernoulli(ϕ)，则 η=log⁡(ϕ/(1−ϕ))\eta = \log(\phi/(1-\phi))η=log(ϕ/(1−ϕ))，ϕ=1/(1+e−η)\phi = 1/(1+e^{-\eta})ϕ=1/(1+e−η)。于是：

hθ(x)=E[y∣x;θ]=ϕ=11+e−η=11+e−θTx.h_\theta(x) = \mathbb{E}[y \mid x; \theta] = \phi = \frac{1}{1+e^{-\eta}} = \frac{1}{1+e^{-\theta^T x}}. hθ​(x)=E[y∣x;θ]=ϕ=1+e−η1​=1+e−θTx1​.

这正是逻辑回归。sigmoid 的出现并非随意选择，而是 GLM 框架的必然产物。

5.4 GLM 的统一算法

对所有 GLM，SGD 更新统一为：

θ:=θ+α(y−hθ(x))x.\theta := \theta + \alpha \left( y - h_\theta(x) \right) x. θ:=θ+α(y−hθ​(x))x.

形式始终是“误差 × 特征”。选定误差分布（由数据类型决定）后，推断、学习、算法全部随之而来。

六、多分类与 Softmax

6.1 设定与独热编码

设 y∈{1,2,…,K}y \in \{1,2,\dots,K\}y∈{1,2,…,K}，用独热向量（one-hot） 表示：y=ky=ky=k 对应 ek∈RKe_k \in \mathbb{R}^Kek​∈RK（第 kkk 位为 1，其余为 0）。输出应为 KKK 个类别的概率分布，满足非负且和为 1。

6.2 Softmax 函数

引入 KKK 组参数 θ1,…,θK∈Rd+1\theta_1, \dots, \theta_K \in \mathbb{R}^{d+1}θ1​,…,θK​∈Rd+1，定义logits（逻辑值） 为 θkTx\theta_k^T xθkT​x。通过 softmax 将 logits 转为概率：

p(y=k∣x;θ)=exp⁡(θkTx)∑j=1Kexp⁡(θjTx),k=1,…,K.p(y=k \mid x; \theta) = \frac{\exp(\theta_k^T x)}{\sum_{j=1}^{K} \exp(\theta_j^T x)},\qquad k=1,\dots,K. p(y=k∣x;θ)=∑j=1K​exp(θjT​x)exp(θkT​x)​,k=1,…,K.

机制：各 logits 经指数放大后归一化，分数越高概率越大。K=2K=2K=2 时退化为逻辑回归（合并为 θ=θ1−θ2\theta = \theta_1 - \theta_2θ=θ1​−θ2​）。

6.3 交叉熵损失

对单个样本，负对数似然为：

ℓce(θ)=−log⁡p(y∣x;θ)=−log⁡(exp⁡(θyTx)∑j=1Kexp⁡(θjTx)).\ell_{\text{ce}}(\theta) = -\log p(y \mid x; \theta) = -\log\left( \frac{\exp(\theta_y^T x)}{\sum_{j=1}^{K} \exp(\theta_j^T x)} \right). ℓce​(θ)=−logp(y∣x;θ)=−log(∑j=1K​exp(θjT​x)exp(θyT​x)​).

用独热标签分布 p^\hat pp^​（真类处为 1，其余 0），可写为：

ℓce(θ)=−∑k=1Kp^klog⁡p(y=k∣x;θ)=−log⁡p(y=真类∣x;θ).\ell_{\text{ce}}(\theta) = -\sum_{k=1}^{K} \hat p_k \log p(y=k \mid x; \theta) = -\log p(y=\text{真类} \mid x; \theta). ℓce​(θ)=−k=1∑K​p^​k​logp(y=k∣x;θ)=−logp(y=真类∣x;θ).

总损失为所有样本之和。梯度为：

∂ℓce∂θk=(p(y=k∣x;θ)−1{y=k})x,\frac{\partial \ell_{\text{ce}}}{\partial \theta_k} = \left( p(y=k \mid x; \theta) - 1\{y=k\} \right) x, ∂θk​∂ℓce​​=(p(y=k∣x;θ)−1{y=k})x,

即“预测概率减真实指示”乘以 xxx，仍是“误差 × 特征”的 GLM 统一形式。

6.4 标签平滑

标签平滑（Label Smoothing） 将硬标签 (1,0,…,0)(1,0,\dots,0)(1,0,…,0) 替换为软标签：

p^k={1−ε,k=y（真类）,ε/(K−1),k≠y,\hat p_k = \begin{cases} 1 - \varepsilon, & k = y \text{（真类）},\\ \varepsilon / (K-1), & k \neq y, \end{cases} p^​k​={1−ε,ε/(K−1),​k=y（真类）,k=y,​

即从真类移出少量概率质量 ε\varepsilonε 均匀分给其他类。此举可视为正则化，防止模型过度自信，提升泛化能力；尤其适用于存在标签噪声或类别不确定性的场景。

七、总结

本笔记覆盖了监督学习的核心链条：

  1. 回归：线性假设 →\to→ 最小二乘 →\to→ 梯度下降/SGD →\to→ 正规方程 →\to→ 高斯噪声下的最大似然解释；
  2. 分类：sigmoid →\to→ 逻辑回归 →\to→ 交叉熵 →\to→ 牛顿法；
  3. 统一框架：指数族 →\to→ GLM →\to→ 线性回归与逻辑回归作为特例 →\to→ 统一的“误差 × 特征” SGD 更新；
  4. 多分类：softmax →\to→ 多类交叉熵 →\to→ 标签平滑。

贯穿始终的主线是最大似然估计：选定误差分布（由数据类型决定），写出似然函数，取对数，求梯度，用 SGD 优化。线性回归、逻辑回归、softmax 多分类皆是此框架在不同数据类型下的具体实例。这套方法论不仅是经典机器学习的基石，也是理解现代深度学习（尤其是分类与语言模型输出层）的必备背景。
